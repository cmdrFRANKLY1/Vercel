Debian GNU/Linux Referenz Debian GNU/Linux Reference

Debian ist eine der ältesten und stabilsten Linux-Distributionen. Es zeichnet sich durch ein strenges Community-Regelwerk (Debian Social Contract, DFSG) und das fortschrittliche Paketverwaltungssystem APT aus. Debian is one of the oldest and most stable Linux distributions. It is characterized by a strict community framework (Debian Social Contract, DFSG) and the advanced package management system APT. 2. APT Paketverwaltung 2. APT Package Management

APT (Advanced Package Tool) ist die hochrangige Schnittstelle zur Paketverwaltung unter Debian. Sie löst Abhängigkeiten automatisch auf und lädt Pakete aus den konfigurierten Quellen herunter. Siehe apt(8) manpage. APT (Advanced Package Tool) is the high-level interface for package management on Debian. It automatically resolves dependencies and downloads packages from the configured sources. See apt(8) manpage.

BefehlCommand BeschreibungDescription BeispielExample
apt update Aktualisiert die Paketlisten aus den konfigurierten Quellen. Updates the package lists from the configured sources.
sudo apt update
apt upgrade Installiert verfügbare Updates, ohne Pakete zu entfernen. Installs available upgrades without removing packages.
sudo apt upgrade
apt full-upgrade Führt ein vollständiges Upgrade durch, entfernt bei Bedarf auch Pakete. Performs a full upgrade, removing packages if necessary.
sudo apt full-upgrade
apt install Installiert ein oder mehrere Pakete inklusive Abhängigkeiten. Installs one or more packages including dependencies.
sudo apt install nginx curl git
apt remove Entfernt Pakete, behält aber Konfigurationsdateien. Removes packages but keeps configuration files.
sudo apt remove nginx
apt purge Entfernt Pakete inklusive ihrer Konfigurationsdateien. Removes packages including their configuration files.
sudo apt purge nginx
apt autoremove Entfernt automatisch installierte Pakete, die nicht mehr benötigt werden. Removes automatically installed packages that are no longer needed.
sudo apt autoremove --purge
apt search Sucht nach Paketen in den verfügbaren Quellen. Searches for packages in the available sources.
apt search nginx
apt show Zeigt detaillierte Informationen zu einem Paket an. Shows detailed information about a package.
apt show nginx
apt list --installed Listet alle installierten Pakete auf. Lists all installed packages.
apt list --installed | grep nginx

3. dpkg & Low-Level-Paketverwaltung 3. dpkg & Low-Level Package Management

dpkg ist das Low-Level-Werkzeug zur Installation und Verwaltung von .deb-Paketen. Es wird von APT im Hintergrund aufgerufen. Siehe dpkg(1) manpage. dpkg is the low-level tool for installing and managing .deb packages. It is called by APT in the background. See dpkg(1) manpage.

BefehlCommand BeschreibungDescription BeispielExample
dpkg -i Installiert ein lokal vorliegendes .deb-Paket. Installs a locally available .deb package.
sudo dpkg -i package.deb
dpkg -l Listet installierte Pakete mit Versionsnummern auf. Lists installed packages with version numbers.
dpkg -l | grep nginx
dpkg -L Listet alle Dateien auf, die zu einem installierten Paket gehören. Lists all files belonging to an installed package.
dpkg -L nginx
dpkg -S Findet heraus, zu welchem Paket eine bestimmte Datei gehört. Finds out which package a specific file belongs to.
dpkg -S /usr/sbin/nginx
dpkg --get-selections Exportiert die Paketauswahl in eine Datei (für Backups/Cloning). Exports the package selection to a file (for backups/cloning).
dpkg --get-selections > packages.txt
dpkg --set-selections Importiert eine Paketauswahl aus einer Datei. Imports a package selection from a file.
sudo dpkg --set-selections < packages.txt
dpkg -V Prüft die Integrität installierter Pakete (MD5-Summen). Verifies the integrity of installed packages (MD5 sums).
dpkg -V

4. Quellen & Repositories 4. Sources & Repositories

Die Datei /etc/apt/sources.list (und Dateien unter /etc/apt/sources.list.d/) definieren, woher APT Pakete bezieht. Siehe sources.list(5). The file /etc/apt/sources.list (and files under /etc/apt/sources.list.d/) define where APT fetches packages from. See sources.list(5).

BefehlCommand BeschreibungDescription BeispielExample
cat /etc/apt/sources.list Zeigt die aktiven Paketquellen an. Shows the active package sources.
cat /etc/apt/sources.list
apt edit-sources Öffnet die Quellenliste in einem Editor (prüft Syntax). Opens the sources list in an editor (validates syntax).
sudo apt edit-sources
apt-cache policy Zeigt die Priorität und Verfügbarkeit von Paketquellen. Shows the priority and availability of package sources.
apt-cache policy nginx

Beispiel: Debian Bookworm sources.list (Ein-Zeilen-Stil) Example: Debian Bookworm sources.list (one-line style)

deb http://deb.debian.org/debian bookworm main non-free-firmware contrib non-free deb http://security.debian.org/debian-security bookworm-security main non-free-firmware contrib non-free

Beispiel: Debian Trixie sources.list (deb822-Stil, modern) Example: Debian Trixie sources.list (deb822 style, modern)

Types: deb URIs: http://deb.debian.org/debian Suites: trixie Components: main contrib non-free-firmware non-free Types: deb URIs: http://security.debian.org/debian-security Suites: trixie-security Components: main contrib non-free-firmware non-free

5. systemd & Dienstverwaltung 5. systemd & Service Management

Debian verwendet systemd als Init-System und Dienstmanager. Siehe systemctl(1) manpage. Debian uses systemd as its init system and service manager. See systemctl(1) manpage.

BefehlCommand BeschreibungDescription BeispielExample
systemctl start Startet einen Dienst sofort. Starts a service immediately.
sudo systemctl start nginx
systemctl enable --now Aktiviert einen Dienst beim Booten und startet ihn sofort. Enables a service at boot and starts it immediately.
sudo systemctl enable --now nginx
systemctl status Zeigt den aktuellen Status eines Dienstes an. Shows the current status of a service.
systemctl status nginx
systemctl restart Startet einen Dienst neu (stop + start). Restarts a service (stop + start).
sudo systemctl restart nginx
systemctl disable Deaktiviert den automatischen Start beim Booten. Disables automatic startup at boot.
sudo systemctl disable nginx
journalctl -u Zeigt die Logs eines bestimmten Dienstes an. Shows the logs of a specific service.
journalctl -u nginx -n 50 --no-pager
systemctl list-units --failed Listet alle fehlgeschlagenen Dienste auf. Lists all failed services.
systemctl list-units --failed

6. Netzwerk (Debian-spezifisch) 6. Networking (Debian-specific)

Debian verwendet je nach Version und Installation entweder ifupdown (/etc/network/interfaces) oder NetworkManager (nmcli). Seit Debian 12 ist NetworkManager der Standard für Desktop-Installationen. Depending on version and installation, Debian uses either ifupdown (/etc/network/interfaces) or NetworkManager (nmcli). Since Debian 12, NetworkManager is the default for desktop installations.

BefehlCommand BeschreibungDescription BeispielExample
ip a Zeigt alle Netzwerkinterfaces und IP-Adressen an. Shows all network interfaces and IP addresses.
ip a
nmcli device status Zeigt den Status aller Netzwerkgeräte (NetworkManager). Shows the status of all network devices (NetworkManager).
nmcli device status
nmcli connection show Listet alle gespeicherten Netzwerkverbindungen auf. Lists all saved network connections.
nmcli connection show
cat /etc/network/interfaces Zeigt die klassische Debian-Netzwerkkonfiguration (ifupdown). Shows the classic Debian network configuration (ifupdown).
cat /etc/network/interfaces
ifup / ifdown Aktiviert/deaktiviert ein Interface gemäß /etc/network/interfaces. Brings an interface up/down according to /etc/network/interfaces.
sudo ifdown eth0 && sudo ifup eth0

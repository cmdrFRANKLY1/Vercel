Arch Linux Referenz Arch Linux Reference

Arch Linux ist eine unabhängig entwickelte, x86-64-basierte GNU/Linux-Distribution, die dem Rolling-Release-Modell folgt und stets die aktuellsten stabilen Softwareversionen bereitstellt. Sie richtet sich an erfahrene GNU/Linux-Nutzer mit einer Do-it-yourself-Einstellung, die bereit sind, die Dokumentation zu lesen und Probleme selbst zu lösen. Klicken Sie auf ein Code-Snippet, um es in die Zwischenablage zu kopieren. Arch Linux is an independently developed, x86-64 general-purpose GNU/Linux distribution that follows a rolling-release model, always providing the latest stable versions of most software. It is targeted at proficient GNU/Linux users with a do-it-yourself attitude who are willing to read the documentation and solve their own problems. 1. Einführung & Philosophie 1. Introduction & Philosophy

Die Arch Way basiert auf fünf Prinzipien: Simplicity (Einfachheit ohne unnötige Zusätze), Modernity (aktuelle Software), Pragmatism (pragmatische Entscheidungen), User centrality (Nutzer im Mittelpunkt) und Versatility (Vielseitigkeit). Arch liefert Software so nah wie möglich am Original (upstream) und überlässt die Konfiguration dem Nutzer. The Arch Way is based on five principles: Simplicity (without unnecessary additions), Modernity (latest software), Pragmatism (pragmatic decisions), User centrality (user in focus), and Versatility. Arch ships software as close as possible to upstream and leaves configuration to the user.

2. Pacman Paketverwaltung 2. Pacman Package Management

Pacman ist der Paketmanager von Arch Linux. Er kombiniert ein einfaches Binärformat mit einem benutzerfreundlichen Build-System. Seit Version 3.0.0 ist pacman das Frontend für libalpm. Siehe pacman(8) manpage. Pacman is Arch Linux's package manager. It combines a simple binary package format with an easy-to-use build system. Since version 3.0.0, pacman has been the front-end for libalpm. See pacman(8) manpage.

3. AUR & AUR-Helfer 3. AUR & AUR Helpers

Das Arch User Repository (AUR) ist ein community-getriebenes Repository für Arch-basierte Distributionen. Es enthält PKGBUILD-Skripte, die von Nutzern beigesteuert werden. Da AUR-Pakete aus Quellcode gebaut werden, ist ein AUR-Helfer wie yay oder paru empfehlenswert. Siehe Arch Wiki - AUR. The Arch User Repository (AUR) is a community-driven repository for Arch-based distributions. It contains PKGBUILD scripts contributed by users. Since AUR packages are built from source, an AUR helper like yay or paru is recommended. See Arch Wiki - AUR.

AUR-Helfer installieren (yay): Installing an AUR helper (yay):

sudo pacman -S --needed git base-devel git clone https://aur.archlinux.org/yay.git cd yay makepkg -si

4. Mirrors & Reflector 4. Mirrors & Reflector

Reflector ist ein Python-Skript, das die neueste Mirror-Liste von der Arch Linux Mirror Status Seite abruft, die aktuellsten Mirrors filtert, nach Geschwindigkeit sortiert und die Datei /etc/pacman.d/mirrorlist überschreibt. Dies beschleunigt jede Paketinstallation erheblich. Siehe Arch Wiki - Reflector. Reflector is a Python script that retrieves the latest mirror list from the Arch Linux Mirror Status page, filters the most up-to-date mirrors, sorts them by speed, and overwrites the /etc/pacman.d/mirrorlist file. This significantly speeds up every package installation. See Arch Wiki - Reflector.

BefehlCommand BeschreibungDescription BeispielExample
reflector Ruft die schnellsten Mirrors ab und speichert sie in der Mirrorlist. Fetches the fastest mirrors and saves them to the mirrorlist.
sudo reflector --sort rate --save /etc/pacman.d/mirrorlist
reflector (gefiltert) Filtert Mirrors nach Land, Protokoll und Aktualität. Filters mirrors by country, protocol, and freshness.
sudo reflector --country Germany --protocol https --latest 10 --sort rate --save /etc/pacman.d/mirrorlist
systemctl enable reflector Richtet einen wöchentlichen Timer ein, der die Mirrorlist automatisch aktualisiert. Sets up a weekly timer that automatically updates the mirrorlist.
sudo systemctl enable --now reflector.timer
cat mirrorlist Zeigt die aktuelle Mirrorlist an, um die Reihenfolge zu prüfen. Shows the current mirrorlist to check the order.
cat /etc/pacman.d/mirrorlist

5. systemd & Dienstverwaltung 5. systemd & Service Management

Arch Linux verwendet systemd als Init-System und Dienstmanager. Die Interaktion erfolgt über systemctl. Siehe Arch Wiki - systemd. Arch Linux uses systemd as its init system and service manager. Interaction is done via systemctl. See Arch Wiki - systemd.

BefehlCommand BeschreibungDescription BeispielExample
systemctl start Startet einen Dienst sofort. Starts a service immediately.
sudo systemctl start nginx
systemctl enable --now Aktiviert einen Dienst beim Booten und startet ihn sofort. Enables a service at boot and starts it immediately.
sudo systemctl enable --now nginx
systemctl status Zeigt den aktuellen Status eines Dienstes an. Shows the current status of a service.
systemctl status nginx
systemctl restart Startet einen Dienst neu (stop + start). Restarts a service (stop + start).
sudo systemctl restart nginx
systemctl disable Deaktiviert den automatischen Start beim Booten. Disables automatic startup at boot.
sudo systemctl disable nginx
journalctl -u Zeigt die Logs eines bestimmten Dienstes an. Shows the logs of a specific service.
journalctl -u nginx -n 50 --no-pager
systemctl list-units --failed Listet alle fehlgeschlagenen Dienste auf. Lists all failed services.
systemctl --failed

6. Netzwerk 6. Networking

Arch Linux bietet mehrere Optionen zur Netzwerkkonfiguration: systemd-networkd (integriert), NetworkManager (nmcli) oder netctl. systemd-networkd ist die Standardwahl für einfache Setups. Siehe Arch Wiki - Network configuration. Arch Linux offers several options for network configuration: systemd-networkd (integrated), NetworkManager (nmcli), or netctl. systemd-networkd is the default choice for simple setups. See Arch Wiki - Network configuration.

systemctl enable systemd-networkd Aktiviert den systemd-networkd-Dienst beim Booten. Enables the systemd-networkd service at boot.

8. Systemwartung 8. System Maintenance

Arch ist ein Rolling-Release-System mit schneller Paketentwicklung. Regelmäßige Systemwartung ist unerlässlich, um ein stabiles System zu erhalten. Siehe Arch Wiki - System maintenance. Arch is a rolling-release system with rapid package turnover. Regular system maintenance is essential to keep a stable system. See Arch Wiki - System maintenance.

BefehlCommand BeschreibungDescription BeispielExample
pacman -Qdtq | pacman -Rns - Entfernt alle verwaisten Pakete (nicht mehr benötigte Abhängigkeiten) auf einmal. Removes all orphaned packages (no longer needed dependencies) at once.
sudo pacman -Qdtq | sudo pacman -Rns -
pacman -Qkk Überprüft die Integrität aller installierten Pakete (Dateirechte, Prüfsummen). Verifies the integrity of all installed packages (file permissions, checksums).
sudo pacman -Qkk
pacman -Sc Bereinigt den Paket-Cache (entfernt alte Paketversionen). Cleans the package cache (removes old package versions).
sudo pacman -Sc
paccache -r Behält nur die letzten 3 Versionen jedes Pakets im Cache (aus pacman-contrib). Keeps only the last 3 versions of each package in the cache (from pacman-contrib).
sudo paccache -r
journalctl --vacuum-time Bereinigt alte systemd-Journal-Logs (z.B. älter als 2 Wochen). Cleans old systemd journal logs (e.g., older than 2 weeks).
sudo journalctl --vacuum-time=2weeks
mkinitcpio -P Baut alle Initramfs-Images neu (nach Kernel-Updates oder Moduländerungen). Rebuilds all initramfs images (after kernel updates or module changes).

sudo mkinitcpio -g /boot/initramfs-test.img

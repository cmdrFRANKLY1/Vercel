Linux chmod Referenz Linux chmod Reference

Der Befehl chmod (change mode) wird in Unix/Linux-Systemen verwendet, um die Zugriffsrechte (Lese-, Schreib- und Ausführungsrechte) von Dateien und Verzeichnissen zu ändern. Dieser Guide erklärt detailliert die symbolische und oktale (numerische) Syntax, Sonderrechte sowie die wichtigsten Flags in der Praxis. The chmod (change mode) command is used in Unix/Linux systems to change the access permissions (read, write, and execute) of files and directories. This guide explains in detail the symbolic and octal (numeric) syntax, special permissions, and the most important practical flags.

2. Grundrechte (rwx) 2. Basic Permissions (rwx)

Linux unterscheidet Rechte für drei Zielgruppen: User (Besitzer), Group (Gruppe) und Others (Alle anderen). Jede Gruppe kann eine Kombination aus drei Grundrechten besitzen. Linux distinguishes permissions for three target groups: User (Owner), Group, and Others. Each group can have a combination of three basic permissions.

SymbolSymbol OktalOctal Bedeutung (Datei)Meaning (File) Bedeutung (Verzeichnis)Meaning (Directory)
r 4 Read: Datei lesen.Read: Read file content. Read: Verzeichnisinhalt auflisten (`ls`).Read: List directory contents (`ls`).
w 2 Write: Datei ändern.Write: Modify file content. Write: Dateien erstellen/löschen/umbenennen.Write: Create/delete/rename files.
x 1 Execute: Datei als Programm ausführen.Execute: Run file as a program. Execute: In Verzeichnis wechseln (`cd`).Execute: Enter the directory (`cd`).
- 0 Kein Recht.No permission.

Beispiel-Ausgabe von ls -l: Example output of ls -l:
-rwxr-xr-- = Datei (-) | User: rwx | Group: r-x | Others: r-- = File (-) | User: rwx | Group: r-x | Others: r--

3. Symbolischer Modus (Buchstaben) 3. Symbolic Mode (Letters)

Der symbolische Modus verwendet Buchstaben, um Zielgruppen, Operatoren und Rechte zu kombinieren. Syntax: chmod [Ziel][Operator][Recht] Datei Symbolic mode uses letters to combine targets, operators, and permissions. Syntax: chmod [Target][Operator][Permission] file

Ziele (Targets) Targets

  • u = user (BesitzerOwner)
  • g = group (GruppeGroup)
  • o = others (AndereOthers)
  • a = all (u+g+o)

Operatoren Operators

  • + = Recht hinzufügenAdd permission
  • - = Recht entziehenRemove permission
  • = = Recht exakt setzenSet exact permission

Beispiele Examples

chmod u+x script.sh

Macht die Datei für den Besitzer (u) ausführbar (+x).Makes the file executable (+x) for the owner (u).

chmod g-w,o-rwx file.txt

Entzieht der Gruppe das Schreibrecht und allen anderen sämtliche Rechte (Kombination mit Komma).Removes write permission from group, and all permissions from others (comma separated).

chmod a=r info.txt

Setzt die Rechte für alle exakt auf "nur lesen" (überschreibt bestehende Rechte).Sets permissions for everyone exactly to "read-only" (overwrites existing).

4. Oktaler Modus (Zahlen) 4. Octal Mode (Numbers)

Der oktale Modus nutzt eine 3-stellige Zahl (bzw. 4-stellig für Sonderrechte), um die Rechte für User, Group und Others gleichzeitig festzulegen. Man addiert dazu die Werte 4 (Read), 2 (Write) und 1 (Execute). The octal mode uses a 3-digit number (or 4-digit for special permissions) to set permissions for User, Group, and Others simultaneously. You add the values 4 (Read), 2 (Write), and 1 (Execute).

Wert 01234567
RechtePerms -----x-w--wxr--r-xrw-rwx

Häufige Setups Common Setups

chmod 755 ordner/

7 (User: rwx), 5 (Group: r-x), 5 (Others: r-x). Standard für Verzeichnisse (jeder darf hinein, aber nur der Besitzer darf ändern).Standard for directories (everyone can enter, only owner can modify).

chmod 644 datei.txt

6 (User: rw-), 4 (Group: r--), 4 (Others: r--). Standard für normale Dateien (sicheres Lesen für alle).Standard for normal files (safe read for everyone).

chmod 777 public_dir/

777 = Alle dürfen alles (Gefährlich! Nur für unkritische Tauschordner).Everyone can do anything (Dangerous! Only for non-critical shared folders).

5. Sonderrechte (SUID, SGID, Sticky) 5. Special Permissions (SUID, SGID, Sticky)

Sonderrechte werden im oktalen Modus durch eine führende vierte Ziffer (z.B. 4755) gesetzt. Special permissions are set in octal mode via a leading fourth digit (e.g., 4755).

TypType Oktal / Sym ErklärungExplanation
SUID
(Set-User-ID)		 4000
u+s		 Wird auf Dateien angewendet. Die Datei wird mit den Rechten des Dateibesitzers (meist root) ausgeführt, nicht mit denen des ausführenden Nutzers (z.B. der passwd Befehl). Applied to files. The file is executed with the permissions of the file owner (usually root), not the user executing it (e.g., the passwd command).
SGID
(Set-Group-ID)		 2000
g+s		 Wird meist auf Verzeichnisse angewandt. Neu erstellte Dateien im Verzeichnis erben die Gruppe des Verzeichnisses (Ideal für Team-Ordner). Mostly applied to directories. Newly created files inherit the group of the directory (Ideal for team folders).
Sticky Bit 1000
+t		 Wird auf Verzeichnisse angewandt. User dürfen nur Dateien löschen/umbenennen, die ihnen selbst gehören (Standard für /tmp). Applied to directories. Users can only delete/rename files they own themselves (Standard for /tmp).

Beispiele:Examples:

chmod 4755 suid_program chmod 2770 team_folder/ chmod 1777 /tmp

6. Praxis & Wichtige Flags 6. Practice & Important Flags

Rekursiv Ändern (-R)Recursive Change (-R)

Wendet die Rechte auf das Verzeichnis und alle darin enthaltenen Dateien und Unterordner an. Applies the permissions to the directory and all files and subdirectories within it.

chmod -R 755 /var/www/html

Großes 'X' beim rekursiven SetzenCapital 'X' in recursive setting

Macht nur Verzeichnisse ausführbar (damit man hineinwechseln kann), lässt aber normale Textdateien in Ruhe. Sehr nützlich für Webserver! Makes only directories executable (so they can be entered) but leaves normal text files alone. Very useful for web servers!

chmod -R u=rwX,go=rX /var/www/html

Referenz-Datei nutzenUse Reference File

Kopiert exakt die Rechte von einer Datei auf eine andere. Copies the exact permissions from one file to another.

chmod --reference=vorlage.txt neue_datei.txt

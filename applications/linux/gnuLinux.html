1. Dateien, Ordner & Navigation 1. Files, Directories & Navigation

BefehlCommand BeschreibungDescription BeispielExample
ls Listet den Inhalt eines Verzeichnisses auf. Lists the contents of a directory.
ls -lah /var/log/
cd Wechselt das aktuelle Arbeitsverzeichnis. Changes the current working directory.
cd /etc/nginx
pwd Gibt den vollständigen Pfad des aktuellen Verzeichnisses aus. Prints the full path of the current directory.
pwd
mkdir Erstellt ein neues Verzeichnis. Mit -p auch verschachtelt. Creates a new directory. With -p also nested.
mkdir -p project/src/bin
rmdir Löscht ein leeres Verzeichnis. Removes an empty directory.
rmdir old_dir
cp Kopiert Dateien oder Verzeichnisse (-r). Copies files or directories (-r).
cp -r src/ backup/
mv Verschiebt oder benennt Dateien/Verzeichnisse um. Moves or renames files/directories.
mv file.txt /tmp/
rm Löscht Dateien oder Verzeichnisse (-r). Removes files or directories (-r).
rm -rf old_build/
touch Erstellt eine leere Datei oder aktualisiert den Zeitstempel. Creates an empty file or updates the timestamp.
touch index.html
ln Erstellt Hard- oder Symbolic-Links (-s). Creates hard or symbolic links (-s).
ln -s /opt/app/current /usr/local/bin/app
find Sucht nach Dateien und Verzeichnissen nach Kriterien. Searches for files and directories by criteria.
find /var -type f -name "*.log"
which Zeigt den Pfad zu einer ausführbaren Datei an. Shows the path to an executable.
which python3
tree Zeigt die Verzeichnisstruktur als Baum an (oft optional). Displays directory structure as a tree (often optional).
tree -L 2 /etc/nginx/

2. Dateiinhalt ansehen 2. Viewing File Content

BefehlCommand BeschreibungDescription BeispielExample
cat Gibt den gesamten Inhalt einer Datei aus. Prints the entire content of a file.
cat /etc/hostname
less Zeigt Dateiinhalte seitenweise an (interaktiv). Views file content page by page (interactive).
less /var/log/syslog
head Zeigt die ersten N Zeilen einer Datei an. Displays the first N lines of a file.
head -n 20 /etc/passwd
tail Zeigt die letzten N Zeilen einer Datei an. Mit -f live verfolgen. Displays the last N lines of a file. With -f follow live.
tail -f /var/log/nginx/access.log
wc Zählt Zeilen, Wörter und Bytes einer Datei. Counts lines, words, and bytes in a file.
wc -l /etc/services
file Bestimmt den Dateityp (Text, Binary, Image etc.). Determines the file type (text, binary, image, etc.).
file archive.tar.gz
stat Zeigt detaillierte Metadaten einer Datei (Inode, Rechte, Zeitstempel). Shows detailed file metadata (inode, permissions, timestamps).
stat /etc/shadow

3. Textverarbeitung 3. Text Processing

BefehlCommand BeschreibungDescription BeispielExample
grep Sucht nach Textmustern in Dateien oder Streams. Searches for text patterns in files or streams.
grep -r "error" /var/log/
sed Stream-Editor für Suchen & Ersetzen in Dateien/Streams. Stream editor for find & replace in files/streams.
sed -i 's/old/new/g' config.txt
awk Mächtiges Tool zur Feld-/Spaltenverarbeitung. Powerful tool for field/column processing.
awk '{print $1, $3}' data.txt
sort Sortiert Zeilen alphabetisch oder numerisch. Sorts lines alphabetically or numerically.
sort -n numbers.txt
uniq Filtert doppelte aufeinanderfolgende Zeilen. Filters duplicate adjacent lines.
sort names.txt | uniq -c
cut Schneidet Felder (Spalten) aus Zeilen heraus. Extracts fields (columns) from lines.
cut -d: -f1 /etc/passwd
diff Vergleicht zwei Dateien Zeile für Zeile. Compares two files line by line.
diff file1.conf file2.conf
tee Leitet Ausgabe gleichzeitig in Datei und auf stdout. Redirects output to both a file and stdout.
ls -la | tee listing.txt
tr Übersetzt oder löscht Zeichen in einem Stream. Translates or deletes characters in a stream.
echo "HELLO" | tr 'A-Z' 'a-z'
xargs Erstellt Argumentlisten aus stdin für andere Befehle. Builds argument lists from stdin for other commands.
find . -name "*.tmp" | xargs rm

4. Berechtigungen & Besitz 4. Permissions & Ownership

BefehlCommand BeschreibungDescription BeispielExample
chmod Ändert die Datei-/Verzeichnisberechtigungen (symbolisch oder oktal). Changes file/directory permissions (symbolic or octal).
chmod 755 script.sh
chown Ändert den Eigentümer und/oder die Gruppe einer Datei. Changes the owner and/or group of a file.
chown www-data:www-data /var/www/
chgrp Ändert nur die Gruppenzugehörigkeit einer Datei. Changes only the group ownership of a file.
chgrp developers project/
umask Zeigt oder setzt die Standard-Dateimaske für neue Dateien. Shows or sets the default file creation mask.
umask 022
sudo Führt einen Befehl mit Root-Rechten aus. Executes a command with root privileges.
sudo systemctl restart nginx
su Wechselt zu einem anderen Benutzer (Standard: root). Switches to another user (default: root).
su - deploy

5. Prozessverwaltung 5. Process Management

BefehlCommand BeschreibungDescription BeispielExample
ps Listet laufende Prozesse auf. Lists running processes.
ps aux | grep nginx
top Echtzeit-Prozessüberwachung mit CPU/RAM-Nutzung. Real-time process monitoring with CPU/RAM usage.
top
kill Sendet ein Signal an einen Prozess (PID). Sends a signal to a process (PID).
kill -9 1234
killall Sendet ein Signal an alle Prozesse eines Namens. Sends a signal to all processes by name.
killall python3
nice Startet einen Prozess mit angepasster Priorität. Starts a process with adjusted priority.
nice -n 10 rsync -avz /data /backup
renice Ändert die Priorität eines laufenden Prozesses. Changes the priority of a running process.
renice -n 5 -p 1234
systemctl Verwaltet systemd-Dienste (Start/Stop/Restart). Manages systemd services (start/stop/restart).
sudo systemctl restart sshd
journalctl Liest Systemd-Logs (journal). Reads systemd journal logs.
journalctl -u nginx -n 50

6. Netzwerk 6. Networking

BefehlCommand BeschreibungDescription BeispielExample
ip Zeigt/konfiguriert Netzwerkinterfaces, Routen und Adressen. Shows/configures network interfaces, routes, and addresses.
ip addr show
ping Testet die Erreichbarkeit eines Hosts via ICMP. Tests host reachability via ICMP.
ping -c 4 8.8.8.8
ss Listet Socket-Statistiken auf (netstat-Ersatz). Lists socket statistics (netstat replacement).
ss -tulpn
curl Überträgt Daten von/zu Servern (HTTP, FTP etc.). Transfers data to/from servers (HTTP, FTP, etc.).
curl -I https://example.com
wget Lädt Dateien aus dem Internet herunter. Downloads files from the internet.
wget https://example.com/file.tar.gz
ssh Stellt eine verschlüsselte Remote-Shell-Verbindung her. Establishes a secure remote shell connection.
ssh user@192.168.1.10
scp Kopiert Dateien sicher über SSH zwischen Hosts. Securely copies files over SSH between hosts.
scp file.tar.gz user@server:/tmp/
dig Fragt DNS-Informationen für einen Hostnamen ab. Queries DNS information for a hostname.
dig +short google.com

7. Archive & Kompression 7. Archiving & Compression

BefehlCommand BeschreibungDescription BeispielExample
tar Erstellt oder entpackt Archivdateien (oft mit gzip/bzip2 kombiniert). Creates or extracts archive files (often combined with gzip/bzip2).
tar -czvf backup.tar.gz /home/user/
gzip Komprimiert einzelne Dateien mit gzip. Compresses individual files with gzip.
gzip large_file.log
gunzip Dekomprimiert .gz-Dateien. Decompresses .gz files.
gunzip large_file.log.gz
zip Erstellt ZIP-Archive (portabel, auch unter Windows lesbar). Creates ZIP archives (portable, also readable on Windows).
zip -r project.zip project/
unzip Entpackt ZIP-Archive. Extracts ZIP archives.
unzip project.zip -d /tmp/

8. Systeminformationen 8. System Information

BefehlCommand BeschreibungDescription BeispielExample
uname Zeigt Systeminformationen (Kernel, Architektur etc.). Shows system information (kernel, architecture, etc.).
uname -a
hostname Zeigt oder setzt den Hostnamen des Systems. Shows or sets the system hostname.
hostname
df Zeigt den belegten und freien Speicherplatz von Dateisystemen. Shows used and free disk space on filesystems.
df -h
du Zeigt die Größe von Dateien und Verzeichnissen an. Shows the size of files and directories.
du -sh /var/log/
free Zeigt den Speicherverbrauch (RAM und Swap) an. Shows memory usage (RAM and swap).
free -h
uptime Zeigt die Systemlaufzeit und Auslastung an. Shows system uptime and load average.
uptime
lsblk Listet Blockgeräte (Festplatten, Partitionen) auf. Lists block devices (disks, partitions).
lsblk -f
dmesg Zeigt Kernel-Meldungen (Boot, Hardware, Treiber). Shows kernel messages (boot, hardware, drivers).
dmesg | tail -20

9. Shell & Umgebung 9. Shell & Environment

BefehlCommand BeschreibungDescription BeispielExample
echo Gibt Text oder Variablenwerte auf stdout aus. Prints text or variable values to stdout.
echo "Hello, $USER"
export Setzt eine Umgebungsvariable für die aktuelle Shell. Sets an environment variable for the current shell.
export PATH="$PATH:/opt/bin"
env Zeigt alle Umgebungsvariablen an. Displays all environment variables.
env | grep HOME
alias Erstellt eine Abkürzung für einen Befehl. Creates a shortcut for a command.
alias ll='ls -alF'
history Zeigt die Befehlshistorie der aktuellen Shell an. Shows the command history of the current shell.
history | grep ssh
man Zeigt die Handbuchseite (man page) eines Befehls an. Displays the manual page of a command.
man chmod
exit Beendet die aktuelle Shell-Sitzung. Exits the current shell session.
exit

10. Sonstiges 10. Miscellaneous

BefehlCommand BeschreibungDescription BeispielExample
date Zeigt oder setzt Datum und Uhrzeit. Shows or sets date and time.
date +"%Y-%m-%d %H:%M"
cal Zeigt einen Kalender im Terminal an. Displays a calendar in the terminal.
cal 2026
sleep Pausiert die Ausführung für eine angegebene Zeit. Pauses execution for a specified time.
sleep 5 && echo "Done"
watch Führt einen Befehl periodisch aus und zeigt die Ausgabe. Runs a command periodically and shows the output.
watch -n 2 'df -h'
bc Beliebiger Präzisions-Taschenrechner auf der Kommandozeile. Arbitrary precision command-line calculator.
echo "scale=2; 10/3" | bc
seq Erzeugt eine Zahlenfolge von Start bis Ende. Generates a sequence of numbers from start to end.
seq 1 5
shred Überschreibt eine Datei sicher, um sie unwiederbringlich zu löschen. Securely overwrites a file to make it unrecoverable.
shred -uvz secret.key

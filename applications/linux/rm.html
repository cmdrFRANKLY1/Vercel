Linux rm Referenz Linux rm Reference

Der Befehl rm (remove) wird in Unix/Linux-Systemen verwendet, um Dateien und Verzeichnisse zu löschen. Im Gegensatz zu Windows oder macOS gibt es hier standardmäßig keinen Papierkorb. Was mit rm gelöscht wird, ist dauerhaft entfernt! The rm (remove) command is used in Unix/Linux systems to delete files and directories. Unlike Windows or macOS, there is no recycle bin by default. What is deleted with `rm` is permanently gone!

1. Wichtige Warnung 1. Important Warning

Seien Sie extrem vorsichtig beim Einsatz von Platzhaltern (Wildcards wie *) und der rekursiven Löschung. Der Befehl verzeiht keine Fehler. Tippfehler können zu massivem Datenverlust oder der Zerstörung des Betriebssystems führen. Be extremely careful when using wildcards (like *) and recursive deletion. The command does not forgive mistakes. Typos can lead to massive data loss or the destruction of the operating system.

2. Grundlegende Nutzung 2. Basic Usage

Einzelne Datei löschen Delete a single file

Löscht eine spezifische Datei. Wenn Sie Schreibrechte haben, wird sie ohne Nachfrage gelöscht. Deletes a specific file. If you have write permissions, it is deleted without prompting.

rm dokument.txtrm document.txt

Mehrere Dateien löschen Delete multiple files

Sie können beliebig viele Dateien durch Leerzeichen getrennt angeben. You can specify any number of files separated by spaces.

rm datei1.log datei2.log datei3.logrm file1.log file2.log file3.log

3. Wichtige Optionen (Flags) 3. Essential Options (Flags)

Flag ErklärungExplanation
-r oder -R Recursive (Rekursiv): Zwingend erforderlich, um ganze Verzeichnisse zu löschen. Löscht den angegebenen Ordner und alle darin enthaltenen Unterordner und Dateien. Ohne dieses Flag weigert sich rm, Ordner zu löschen. Recursive: Mandatory for deleting directories. Deletes the specified folder and all its contents (subfolders and files). Without this flag, rm refuses to delete folders.
-f Force (Erzwingen): Löscht Dateien ohne nachzufragen, auch wenn sie schreibgeschützt sind. Ignoriert zudem Fehlermeldungen, wenn eine Datei gar nicht existiert. Sehr gefährlich in Kombination mit -r! Force: Deletes files without prompting, even if they are write-protected. Also ignores errors if a file doesn't exist. Very dangerous in combination with -r!
-i Interactive (Interaktiv): Fragt vor dem Löschen jeder einzelnen Datei nach einer Bestätigung (y/n). Eine sehr gute Sicherheitsmaßnahme. Interactive: Prompts for confirmation (y/n) before deleting every single file. A very good safety measure.
-v Verbose (Ausführlich): Zeigt auf dem Bildschirm an, was gerade gelöscht wird. Verbose: Prints a message on the screen for every file it deletes.

Beispiele:Examples:

Einen ganzen Ordner samt Inhalt löschen:Delete an entire folder and its contents:

rm -r alter_ordner/rm -r old_folder/

Der "Zerstörer" (Ohne Nachfrage alles im Ordner löschen):The "Destroyer" (Delete everything in the folder without asking):

rm -rf altes_projekt/rm -rf old_project/

4. Sicherheits-Tipps & Best Practices 4. Safety Tips & Best Practices

Der Trockenlauf mit lsThe dry-run using ls

Bevor Sie einen Wildcard (*) zum Löschen verwenden, testen Sie ihn immer zuerst mit ls, um zu sehen, was genau erfasst wird! Before using a wildcard (*) for deletion, always test it first with ls to see exactly what gets matched!

ls *.txt # Erst testen! rm *.txt # Dann löschenls *.txt # Test first! rm *.txt # Then delete

Der Kompromiss: -I (Großes i)The compromise: -I (Capital i)

Das kleine -i fragt bei jeder Datei. Das große -I fragt nur ein einziges Mal nach, wenn Sie mehr als 3 Dateien oder rekursiv löschen wollen. Ein toller Schutz gegen versehentliches rm *. The lowercase -i asks for every file. The uppercase -I prompts only once if you are deleting more than 3 files or deleting recursively. A great protection against accidental rm *.

rm -I *.log

5. Häufige Fehler 5. Common Errors

Is a directory

rm: cannot remove 'bilder': Is a directoryrm: cannot remove 'pictures': Is a directory

Ursache: Sie versuchen, einen Ordner ohne das -r Flag zu löschen.
Lösung: Nutzen Sie rm -r bilder. Cause: You are trying to delete a folder without the -r flag.
Solution: Use rm -r pictures.

Permission denied

rm: cannot remove '/etc/config.txt': Permission denied

Ursache: Sie haben keine Schreibrechte für die Datei oder den übergeordneten Ordner.
Lösung: Verwenden Sie sudo rm ... (mit äußerster Vorsicht!). Cause: You don't have write permissions for the file or its parent folder.
Solution: Use sudo rm ... (with extreme caution!).

No such file or directory

rm: cannot remove 'geheim.txt': No such file or directoryrm: cannot remove 'secret.txt': No such file or directory

Ursache: Die Datei existiert nicht, Sie befinden sich im falschen Ordner, oder Sie haben sich vertippt.
Lösung: Prüfen Sie mit ls, ob die Datei da ist. Wenn Sie den Fehler in Skripten ignorieren wollen, nutzen Sie rm -f. Cause: The file doesn't exist, you are in the wrong folder, or there is a typo.
Solution: Check if the file is there using ls. If you want to ignore this error in scripts, use rm -f.

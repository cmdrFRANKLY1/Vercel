Linux cd Referenz Linux cd Reference

Der Befehl cd (change directory) ist in Unix/Linux-Systemen unerlässlich, um das aktuelle Arbeitsverzeichnis im Terminal zu wechseln. Da cd ein Shell-Builtin ist (und kein externes Programm), ist er extrem schnell. Dieser Guide erklärt Pfade, Shortcuts und den Umgang mit Symlinks. The cd (change directory) command is essential in Unix/Linux systems for changing the current working directory in the terminal. Because cd is a shell builtin (and not an external program), it is extremely fast. This guide explains paths, shortcuts, and handling symlinks.

1. Einführung: Absolute vs. Relative Pfade 1. Introduction: Absolute vs. Relative Paths

Beim Navigieren mit cd können Sie den Zielordner auf zwei Arten angeben. When navigating with cd, you can specify the target folder in two ways.

Absolute Pfade Absolute Paths

Beginnen immer mit einem Schrägstrich / (Root-Verzeichnis). Der Pfad ist vom aktuellen Standort unabhängig. Always start with a forward slash / (root directory). The path works regardless of your current location.

cd /var/log/nginx cd /etc/ssh

Relative Pfade Relative Paths

Gehen vom aktuellen Verzeichnis aus. Sie beginnen nicht mit einem Schrägstrich. Start from the current directory. They do not start with a forward slash.

cd Downloads/Music cd ../src

2. Wichtige Shortcuts 2. Essential Shortcuts

BefehlCommand ErklärungExplanation
cd
oder / or
cd ~		 Wechselt sofort in das Home-Verzeichnis des aktuellen Benutzers (z.B. /home/user).
cd ~username wechselt in das Home-Verzeichnis eines anderen Benutzers. Switches immediately to the current user's home directory (e.g. /home/user).
cd ~username switches to another user's home directory.
cd .. Geht im Verzeichnisbaum eine Ebene nach oben in das Elternverzeichnis (Parent Directory). Um zwei Ebenen hochzugehen: cd ../.. Moves one level up in the directory tree to the parent directory. To move up two levels: cd ../..
cd - Wechselt zurück in das zuletzt besuchte Verzeichnis (Previous Directory). Sehr nützlich, um zwischen zwei Ordnern hin- und herzuspringen. Switches back to the previously visited directory. Very useful for jumping back and forth between two folders.
cd / Wechselt direkt in das Root-Verzeichnis (Wurzelverzeichnis), die höchste Ebene im Dateisystem. Switches directly to the root directory, the highest level in the file system hierarchy.

3. Leerzeichen & Sonderzeichen im Namen 3. Spaces & Special Characters

Wenn ein Verzeichnis Leerzeichen enthält, liest die Shell jedes Wort als separates Argument. Um dies zu verhindern, müssen Sie den Pfad entweder in Anführungszeichen setzen oder das Leerzeichen escapen (mit einem Backslash). If a directory contains spaces, the shell reads each word as a separate argument. To prevent this, you must either wrap the path in quotes or escape the space (using a backslash).

Methode 1: Anführungszeichen (Empfohlen)Method 1: Quotes (Recommended)

cd "My Documents" cd 'Backup 2026'

Methode 2: Backslash (Escaping)Method 2: Backslash (Escaping)

cd My\ Documents

Verzeichnisse, die mit einem Bindestrich beginnenDirectories starting with a dash

Wenn ein Ordner -reports heißt, denkt cd fälschlicherweise, -r sei eine Option. Verwenden Sie --, um das Ende der Optionen zu signalisieren: If a folder is named -reports, cd mistakenly thinks -r is an option. Use -- to signal the end of options:

cd -- -reports

4. Optionen (-P vs. -L) und Symlinks 4. Options (-P vs. -L) and Symlinks

Ein symbolischer Link (Symlink) ist eine Verknüpfung, die auf einen anderen Ordner zeigt. Der cd-Befehl geht standardmäßig davon aus, dass Sie den logischen Pfad beibehalten wollen. A symbolic link (symlink) is a shortcut pointing to another folder. By default, the cd command assumes you want to keep the logical path.

Flag ErklärungExplanation
-L Logical (Standard): Folgt dem Symlink und zeigt den Symlink-Pfad im Prompt an. Logical (Default): Follows the symlink and displays the symlink path in the prompt.
-P Physical: Löst den Symlink auf und wechselt in den physischen (echten) Zielordner. Physical: Resolves the symlink and switches to the physical (actual) target folder.

Beispiel:Example:

Angenommen, /var/www/html ist ein Link auf /mnt/data/web. Assuming /var/www/html is a link to /mnt/data/web.

cd -P /var/www/html pwd # Output: /mnt/data/web

5. Häufige Fehler 5. Common Errors

Permission denied

bash: cd: /root: Permission denied

Ursache: Sie haben keine Lese-/Ausführungsrechte für diesen Ordner. Verwenden Sie sudo su oder wechseln Sie zu einem privilegierten Benutzer. Cause: You don't have read/execute permissions for this folder. Use sudo su or switch to a privileged user.

No such file or directory

bash: cd: /invalid/path: No such file or directory

Ursache: Der Ordner existiert nicht oder Sie haben sich vertippt. Denken Sie daran: Linux unterscheidet zwischen Groß- und Kleinschreibung (Dokumente vs. dokumente). Cause: The folder does not exist or there is a typo. Remember: Linux is case-sensitive (Documents vs. documents).

Not a directory

bash: cd: /etc/passwd: Not a directory

Ursache: Sie versuchen, in eine Datei zu wechseln. cd funktioniert nur mit Verzeichnissen. Cause: You are trying to cd into a file. cd only works with directories.

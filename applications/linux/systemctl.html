Linux systemctl Referenz Linux systemctl Reference

Der Befehl systemctl ist das zentrale Werkzeug zur Steuerung des systemd-Init-Systems und Service-Managers in modernen Linux-Distributionen. Er ermöglicht die Verwaltung von Diensten, Zielen (Targets), Mounts und Systemzuständen. The systemctl command is the central utility for controlling the systemd init system and service manager in modern Linux distributions. It allows managing services, targets, mounts, and system states.

1. Einführung & Grundlagen 1. Introduction & Basics

In systemd wird fast jede Komponente als Unit bezeichnet (z.B. nginx.service, fstrim.timer oder home.mount). Wenn Sie den Dateinamen-Suffix weglassen (wie .service), nimmt systemd diesen automatisch an. In systemd, almost every resource managed is called a Unit (e.g., nginx.service, fstrim.timer, or home.mount). If you omit the suffix (like .service), systemd infers it automatically.

2. Dienste steuern (Start, Stop, Restart) 2. Managing Services

Dienst starten Start a service

Startet einen inaktiven Dienst sofort. Starts an inactive service immediately.

sudo systemctl start nginx

Dienst stoppen Stop a service

Beendet einen laufenden Dienst sofort. Stops a running service immediately.

sudo systemctl stop nginx

Neustarten / Neu laden Restart / Reload

restart stoppt und startet den Dienst neu. reload lädt die Konfiguration ohne Verbindungsabbruch neu. restart stops and starts the service. reload reloads config without dropping connections.

sudo systemctl restart nginx sudo systemctl reload nginx

Sanfter Neustart Conditional Restart

Startet den Dienst nur neu, wenn er bereits läuft. Restarts the service only if it is already running.

sudo systemctl try-restart nginx

3. Status & Diagnose 3. Status & Diagnostics

Befehl ErklärungExplanation
systemctl status <dienst> Zeigt den aktuellen Zustand (aktiv/inaktiv), PID, Hauptprozess und die letzten Log-Ausgaben an. Shows current state (active/inactive), PID, main process, and recent log excerpts.
systemctl is-active <dienst> Gibt "active" oder "inactive" zurück (ideal für Shell-Skripte). Returns "active" or "inactive" (ideal for shell scripts).
systemctl is-failed <dienst> Prüft, ob ein Dienst mit einem Fehler abgestürzt ist ("failed"). Checks if a service crashed with an error ("failed").
systemctl list-units --type=service Listet alle geladenen Service-Units auf dem System auf. Lists all loaded service units on the system.

Beispiel-Aufruf:Example usage:

systemctl status sshd

4. Autostart (Enable / Disable) 4. Boot Control (Enable / Disable)

Mit diesen Befehlen legen Sie fest, ob ein Dienst beim Hochfahren des Systems automatisch gestartet wird. These commands determine whether a service starts automatically when the system boots up.

enable / disable

Aktiviert oder deaktiviert den automatischen Start beim Systemstart.Enables or disables automatic startup at boot.

sudo systemctl enable nginx sudo systemctl disable nginx

--now

Kann an enable/disable angehängt werden, um den Dienst sofort zu starten bzw. zu stoppen.Can be appended to enable/disable to start or stop the service immediately.

sudo systemctl enable --now nginx

5. System-Zustand (Reboot / Shutdown) 5. System State (Reboot / Shutdown)

systemctl ersetzt auch klassische Befehle wie reboot oder poweroff, indem es systemd-Targets ansteuert. systemctl also replaces traditional commands like reboot or poweroff by invoking systemd targets.

Befehl ErklärungExplanation
sudo systemctl reboot Startet das System neu.Reboots the system.
sudo systemctl poweroff Fährt das System herunter und schaltet es aus.Powers down and turns off the system.
sudo systemctl suspend Versetzt den Rechner in den Energiesparmodus (Standby).Puts the computer into sleep/suspend mode.
sudo systemctl daemon-reload Lädt systemd Konfigurationsdateien neu (wichtig nach dem Erstellen eigener Services).Reloads systemd config files (essential after creating custom service files).

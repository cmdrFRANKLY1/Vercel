Red Hat Enterprise Linux Referenz Red Hat Enterprise Linux Reference

Red Hat Enterprise Linux (RHEL) ist eine kommerzielle Open-Source-Linux-Distribution, die von Red Hat für Unternehmen entwickelt wurde. Sie zeichnet sich durch langfristigen Support (10 Jahre pro Major-Version), zertifizierte Hardware/Software und enterprise-grade Sicherheitsfunktionen wie SELinux aus. Diese Referenz konzentriert sich auf die wichtigsten Werkzeuge für Systemadministratoren: Subscription-Manager, DNF, SELinux, firewalld und die Cockpit-Webkonsole. Klicken Sie auf ein Code-Snippet, um es in die Zwischenablage zu kopieren. Red Hat Enterprise Linux (RHEL) is a commercial open-source Linux distribution developed by Red Hat for enterprises. It features long-term support (10 years per major version), certified hardware/software, and enterprise-grade security features like SELinux. This reference focuses on the essential tools for system administrators: Subscription Manager, DNF, SELinux, firewalld, and the Cockpit web console. 2. Subscription-Manager 2. Subscription Manager

Im Gegensatz zu Community-Distributionen benötigt RHEL ein gültiges Abonnement, um Pakete von Red Hats CDN zu beziehen. Das subscription-manager-Tool verwaltet Registrierung, Subscriptions und Repositories. Mit Simple Content Access (SCA) (Standard seit RHEL 9) entfällt das manuelle Anhängen von Subscriptions. Siehe Configuring and Managing Subscriptions. Unlike community distributions, RHEL requires a valid subscription to pull packages from Red Hat's CDN. The subscription-manager tool manages registration, subscriptions, and repositories. With Simple Content Access (SCA) (default since RHEL 9), manually attaching subscriptions is no longer necessary. See Configuring and Managing Subscriptions.

BefehlCommand BeschreibungDescription BeispielExample
subscription-manager register Registriert das System bei Red Hat mit Benutzername/Passwort. Registers the system with Red Hat using username/password.
sudo subscription-manager register --username=user --password=pass
subscription-manager register (Org/Key) Registriert das System mit Organisations-ID und Activation Key (für automatisierte Deployments). Registers the system using Organization ID and Activation Key (for automated deployments).
sudo subscription-manager register --org=1234567 --activationkey=my-key
subscription-manager status Zeigt den aktuellen Subscription-Status und ob Simple Content Access aktiv ist. Shows current subscription status and whether Simple Content Access is enabled.
sudo subscription-manager status
subscription-manager repos --list Listet alle für das System verfügbaren Repositories auf. Lists all repositories available to the system.
sudo subscription-manager repos --list
subscription-manager repos --enable Aktiviert ein bestimmtes Repository (z.B. CodeReady Builder). Enables a specific repository (e.g., CodeReady Builder).
sudo subscription-manager repos --enable=rhel-9-for-x86_64-codeready-builder-rpms
subscription-manager unregister Meldet das System ab und entfernt alle Subscriptions. Unregisters the system and removes all subscriptions.
sudo subscription-manager unregister
subscription-manager clean Löscht alle Subscription-Daten und Repo-Konfigurationen (für Re-Registrierung). Removes all subscription data and repo configurations (for re-registration).
sudo subscription-manager clean

3. DNF Paketverwaltung 3. DNF Package Management

DNF (Dandified YUM) ist der Standard-Paketmanager in RHEL 8 und 9. Er löste YUM ab und bietet bessere Performance sowie eine modernere API. yum ist in RHEL 8/9 ein Alias für dnf. Siehe Managing Software with the DNF Tool. DNF (Dandified YUM) is the default package manager in RHEL 8 and 9. It replaced YUM and offers better performance and a more modern API. yum is an alias for dnf in RHEL 8/9. See Managing Software with the DNF Tool.

4. RPM & Low-Level-Paketverwaltung 4. RPM & Low-Level Package Management

RPM (RPM Package Manager) ist das Low-Level-Werkzeug zur Installation und Verwaltung von .rpm-Paketen. Es wird von DNF im Hintergrund aufgerufen. Siehe RPM Documentation. RPM (RPM Package Manager) is the low-level tool for installing and managing .rpm packages. It is called by DNF in the background. See RPM Documentation.

BefehlCommand BeschreibungDescription BeispielExample

5. SELinux (Security-Enhanced Linux) 5. SELinux (Security-Enhanced Linux)

SELinux ist ein obligatorisches Zugriffskontrollsystem (MAC), das in RHEL standardmäßig aktiviert ist. Es erzwingt Sicherheitsrichtlinien auf Basis von Typen, Rollen und Booleans – selbst wenn ein Prozess als root läuft, kann SELinux ihn einschränken. Siehe Using SELinux. SELinux is a mandatory access control (MAC) system enabled by default in RHEL. It enforces security policies based on types, roles, and booleans – even if a process runs as root, SELinux can restrict it. See Using SELinux.

BefehlCommand BeschreibungDescription BeispielExample
getenforce Zeigt den aktuellen SELinux-Modus an (Enforcing, Permissive, Disabled). Shows the current SELinux mode (Enforcing, Permissive, Disabled).
getenforce
sestatus Zeigt detaillierten SELinux-Status (Policy, Modus, geladene Module). Shows detailed SELinux status (policy, mode, loaded modules).
sestatus
setenforce Wechselt temporär zwischen Enforcing (1) und Permissive (0). Temporarily switches between Enforcing (1) and Permissive (0).
sudo setenforce 0
getsebool -a Listet alle SELinux-Booleans mit ihrem aktuellen Status auf. Lists all SELinux booleans with their current status.
getsebool -a | grep httpd
setsebool -P Setzt einen SELinux-Boolean dauerhaft (-P = persistent). Sets an SELinux boolean permanently (-P = persistent).
sudo setsebool -P httpd_can_network_connect on
ls -Z Zeigt den SELinux-Kontext von Dateien und Verzeichnissen an. Shows the SELinux context of files and directories.
ls -Z /var/www/html/
restorecon -Rv Stellt SELinux-Standardkontexte für Dateien wieder her (rekursiv). Restores default SELinux contexts for files (recursive).
sudo restorecon -Rv /var/www/html/
semanage port -a Fügt einen Port zu einem SELinux-Typ hinzu (z.B. HTTP auf Port 8080). Adds a port to an SELinux type (e.g., HTTP on port 8080).
sudo semanage port -a -t http_port_t -p tcp 8080
ausearch -m avc Sucht nach SELinux-Denials (AVC-Meldungen) im Audit-Log. Searches for SELinux denials (AVC messages) in the audit log.
sudo ausearch -m avc -ts recent
sealert SELinux-Troubleshooter (GUI) zur Analyse von AVC-Meldungen und Vorschlägen. SELinux troubleshooter (GUI) for analyzing AVC messages and suggestions.
sudo sealert -a /var/log/audit/audit.log

6. firewalld 6. firewalld

firewalld ist die Standard-Firewall-Verwaltung in RHEL. Im Gegensatz zu iptables arbeitet es mit Zonen – jede Zone definiert eine Vertrauensstufe für Netzwerkverbindungen. Die Konfiguration erfolgt über firewall-cmd. Siehe Configuring Firewalls and Packet Filters. firewalld is the default firewall management tool in RHEL. Unlike iptables, it uses zones – each zone defines a trust level for network connections. Configuration is done via firewall-cmd. See Configuring Firewalls and Packet Filters.

BefehlCommand BeschreibungDescription BeispielExample
firewall-cmd --state Prüft, ob firewalld läuft. Checks whether firewalld is running.
firewall-cmd --state
firewall-cmd --get-default-zone Zeigt die Standard-Zone an (in RHEL: public). Shows the default zone (in RHEL: public).
firewall-cmd --get-default-zone
firewall-cmd --list-all Zeigt die vollständige Konfiguration der aktiven Zone an. Shows the complete configuration of the active zone.
sudo firewall-cmd --list-all
firewall-cmd --add-service Erlaubt einen vordefinierten Dienst dauerhaft (--permanent). Allows a predefined service permanently (--permanent).
sudo firewall-cmd --permanent --add-service=http
firewall-cmd --add-port Erlaubt einen bestimmten Port (z.B. 8080/tcp) dauerhaft. Allows a specific port (e.g., 8080/tcp) permanently.
sudo firewall-cmd --permanent --add-port=8080/tcp
firewall-cmd --reload Lädt die Firewall-Regeln neu, ohne bestehende Verbindungen zu unterbrechen. Reloads firewall rules without interrupting existing connections.
sudo firewall-cmd --reload
firewall-cmd --change-interface Weist ein Interface einer anderen Zone zu (dauerhaft). Assigns an interface to a different zone (permanent).
sudo firewall-cmd --zone=trusted --change-interface=eth0 --permanent
firewall-cmd --remove-service Entfernt einen Dienst aus der Firewall-Konfiguration. Removes a service from the firewall configuration.
sudo firewall-cmd --permanent --remove-service=http

7. Cockpit Web Console 7. Cockpit Web Console

Cockpit ist eine webbasierte Verwaltungsoberfläche für Linux-Server, die von Red Hat entwickelt wurde und in RHEL enthalten ist. Sie ermöglicht Systemüberwachung, Dienstverwaltung, Storage-Management, Log-Viewer, Netzwerkkonfiguration und sogar ein Browser-Terminal – alles über Port 9090. Siehe Managing Systems Using the RHEL Web Console. Cockpit is a web-based management interface for Linux servers, developed by Red Hat and included in RHEL. It enables system monitoring, service management, storage management, log viewer, network configuration, and even a browser terminal – all via port 9090. See Managing Systems Using the RHEL Web Console.

BefehlCommand BeschreibungDescription BeispielExample
dnf install cockpit Installiert Cockpit und optionale Module (Storage, PackageKit). Installs Cockpit and optional modules (Storage, PackageKit).
sudo dnf install -y cockpit cockpit-storaged cockpit-packagekit
systemctl enable --now cockpit.socket Aktiviert den Cockpit-Socket (startet bei Bedarf auf Port 9090). Enables the Cockpit socket (starts on demand on port 9090).
sudo systemctl enable --now cockpit.socket
firewall-cmd --add-service=cockpit Öffnet den Cockpit-Port (9090) in der Firewall. Opens the Cockpit port (9090) in the firewall.
sudo firewall-cmd --permanent --add-service=cockpit && sudo firewall-cmd --reload
ss -tlnp | grep 9090 Prüft, ob Cockpit auf Port 9090 lauscht. Checks whether Cockpit is listening on port 9090.
ss -tlnp | grep 9090
systemctl status cockpit.socket Zeigt den Status des Cockpit-Sockets an. Shows the status of the Cockpit socket.
systemctl status cockpit.socket

Zugriff: https://<server-ip>:9090 (selbstsigniertes Zertifikat standardmäßig). Access: https://<server-ip>:9090 (self-signed certificate by default).

8. systemd & Dienstverwaltung 8. systemd & Service Management

RHEL verwendet systemd als Init-System und Dienstmanager. Alle Dienste werden als Units verwaltet (Service, Socket, Target, Timer, Mount, Path). Siehe Managing systemd Services. RHEL uses systemd as its init system and service manager. All services are managed as units (Service, Socket, Target, Timer, Mount, Path). See Managing systemd Services.

BefehlCommand BeschreibungDescription BeispielExample
systemctl start Startet einen Dienst sofort. Starts a service immediately.
sudo systemctl start httpd
systemctl enable --now Aktiviert einen Dienst beim Booten und startet ihn sofort. Enables a service at boot and starts it immediately.
sudo systemctl enable --now httpd
systemctl status Zeigt den aktuellen Status eines Dienstes an. Shows the current status of a service.
systemctl status httpd
systemctl restart Startet einen Dienst neu (stop + start). Restarts a service (stop + start).
sudo systemctl restart httpd
systemctl reload Lädt die Konfiguration neu, ohne den Dienst zu unterbrechen (SIGHUP). Reloads configuration without interrupting the service (SIGHUP).
sudo systemctl reload httpd
systemctl mask Blockiert einen Dienst vollständig (verhindert sogar manuellen Start). Blocks a service completely (prevents even manual start).
sudo systemctl mask firewalld
systemctl --failed Listet alle fehlgeschlagenen Units auf. Lists all failed units.

journalctl -u Zeigt die Logs eines bestimmten Dienstes an. Shows the logs of a specific service.

9. Systemwartung 9. System Maintenance

Regelmäßige Wartung hält ein RHEL-System sicher und stabil. Dazu gehören Paket-Cache-Bereinigung, Log-Rotation, Subscription-Überprüfung und die Kontrolle von SELinux-Meldungen. Siehe Managing Software with DNF. Regular maintenance keeps a RHEL system secure and stable. This includes package cache cleaning, log rotation, subscription checks, and monitoring SELinux messages. See Managing Software with DNF.

BefehlCommand BeschreibungDescription BeispielExample
dnf clean all Entfernt alle zwischengespeicherten Pakete und Metadaten aus dem DNF-Cache. Removes all cached packages and metadata from the DNF cache.
sudo dnf clean all
dnf autoremove Entfernt nicht mehr benötigte Abhängigkeiten automatisch. Automatically removes unneeded dependencies.
sudo dnf autoremove
journalctl --vacuum-time Bereinigt alte systemd-Journal-Logs (z.B. älter als 2 Wochen). Cleans old systemd journal logs (e.g., older than 2 weeks).
sudo journalctl --vacuum-time=2weeks
dnf check-update Prüft, ob Updates verfügbar sind, ohne sie zu installieren. Checks if updates are available without installing them.
sudo dnf check-update
subscription-manager status Überprüft regelmäßig den Subscription-Status des Systems. Regularly checks the system's subscription status.
sudo subscription-manager status
rpm -Va Überprüft die Integrität aller installierten Pakete (Dateigröße, Rechte, MD5). Verifies the integrity of all installed packages (file size, permissions, MD5).
rpm -Va
dnf history rollback Macht eine DNF-Transaktion rückgängig (Rollback). Reverts a DNF transaction (rollback).
sudo dnf history rollback 5

Linux mv Referenz Linux mv Reference

Der Befehl mv (move) wird in Unix/Linux-Systemen verwendet, um Dateien und Verzeichnisse an einen anderen Ort zu verschieben oder ihnen einen neuen Namen zu geben (Umbenennen). Da das Verschieben auf demselben Dateisystem lediglich den Verzeichniseintrag ändert (In-place), ist dieser Vorgang extrem schnell. The mv (move) command is used in Unix/Linux systems to move files and directories to a different location or to rename them. Since moving within the same filesystem simply updates the directory entry, the operation is instantaneous.

1. Einführung & Grundsyntax 1. Introduction & Basic Syntax

Die allgemeine Syntax lautet mv [Optionen] Quelle Ziel. Je nachdem, ob das Ziel eine vorhandene Datei, ein Ordner oder ein neuer Name ist, verhält sich der Befehl unterschiedlich. The general syntax is mv [options] source target. Depending on whether the target is an existing file, a folder, or a new name, the command behaves accordingly.

2. Dateien & Verzeichnisse umbenennen 2. Renaming Files & Directories

Einzelne Datei umbenennen Rename a single file

Ändert den Namen von alt.txt zu neu.txt im selben Verzeichnis. Changes the name from old.txt to new.txt in the same directory.

mv alt.txt neu.txtmv old.txt new.txt

Ordner umbenennen Rename a directory

Verzeichnisse werden exakt wie Dateien umbenannt (kein -r Flag nötig). Directories are renamed just like files (no -r flag needed).

mv projekt_v1/ projekt_v2/mv project_v1/ project_v2/

3. Dateien & Verzeichnisse verschieben 3. Moving Files & Directories

Befehl ErklärungExplanation
mv datei.txt ordner/mv file.txt folder/ Verschiebt eine Datei in einen existierenden Unterordner. Moves a file into an existing subfolder.
mv d1.txt d2.txt ziel_ordner/mv f1.txt f2.txt target_dir/ Verschiebt mehrere Dateien gleichzeitig in einen Zielordner. Das letzte Argument muss hierbei zwingend ein Verzeichnis sein! Moves multiple files into a target directory simultaneously. The last argument must always be a directory!
mv file.txt ../parent_dir/ Verschiebt eine Datei relativ in das übergeordnete Verzeichnis. Relatively moves a file into the parent directory.

4. Wichtige Optionen (Flags) 4. Essential Options (Flags)

Flag ErklärungExplanation
-i Interactive (Interaktiv): Warnt und fragt nach Bestätigung (y/n), bevor eine bestehende Zieldatei überschrieben wird. Verhindert Datenverlust. Interactive: Prompts for confirmation (y/n) before overwriting an existing destination file. Prevents accidental data loss.
-f Force (Erzwingen): Überschreibt Zieldateien ohne Nachfrage. Dies ist das Standardverhalten auf vielen Linux-Systemen (oft via Shell-Alias voreingestellt). Force: Overwrites destination files without prompting. This is default behavior on many Linux systems (often aliased).
-n No clobber (Nicht überschreiben): Verhindert strikt, dass bestehende Dateien überschrieben werden. Existiert das Ziel bereits, wird der Kopiervorgang stumm übersprungen. No clobber: Strictly prevents overwriting existing files. If the destination already exists, the move is silently skipped.
-v Verbose (Ausführlich): Zeigt auf dem Bildschirm an, welche Aktionen gerade ausgeführt werden. Verbose: Prints a message on the screen for every move operation performed.

Beispiel mit Sicherheitsabfrage:Example with safety prompt:

mv -i bericht.txt backup/mv -i report.txt backup/

5. Häufige Fehler 5. Common Errors

Not a directory

mv: target 'datei.txt' is not a directorymv: target 'file.txt' is not a directory

Ursache: Sie versuchen, mehrere Dateien in ein Ziel zu verschieben, das gar kein Ordner ist, sondern eine normale Datei.
Lösung: Stellen Sie sicher, dass das letzte Argument ein existierendes Verzeichnis ist. Cause: You are trying to move multiple files into a target that is a regular file, not a directory.
Solution: Ensure the last argument is an existing directory.

Permission denied

mv: cannot move 'config.txt': Permission denied

Ursache: Ihnen fehlen die Schreibrechte im Quell- oder Zielverzeichnis.
Lösung: Nutzen Sie Administratorrechte mit sudo mv .... Cause: You lack write permissions in the source or target directory.
Solution: Use administrator privileges with sudo mv ....

No such file or directory

mv: cannot stat 'notizen.txt': No such file or directorymv: cannot stat 'notes.txt': No such file or directory

Ursache: Die Quelldatei existiert im aktuellen Pfad nicht oder es liegt ein Tippfehler vor.
Lösung: Überprüfen Sie den Dateinamen mit ls. Cause: The source file doesn't exist in the current path or there is a typo.
Solution: Verify the filename using ls.

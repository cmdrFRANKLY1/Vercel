Linux mkdir Referenz Linux mkdir Reference

Der Befehl mkdir (make directory) wird in Unix/Linux-Systemen verwendet, um neue Verzeichnisse (Ordner) zu erstellen. Er ist ein fundamentaler Bestandteil der Dateisystemverwaltung und bietet nützliche Flags zum Erstellen ganzer Verzeichnisstrukturen auf einmal. The mkdir (make directory) command is used in Unix/Linux systems to create new directories (folders). It is a fundamental part of file system management and offers useful flags for creating entire directory structures at once.

1. Einführung & Basics 1. Introduction & Basics

Standardmäßig erstellt mkdir ein neues Verzeichnis im aktuellen Pfad. Sie können auch mehrere Verzeichnisse gleichzeitig erstellen, indem Sie sie durch Leerzeichen trennen. By default, mkdir creates a new directory in the current path. You can also create multiple directories simultaneously by separating them with spaces.

Einzelnes Verzeichnis Single Directory

Erstellt einen einzelnen neuen Ordner im aktuellen Verzeichnis. Creates a single new folder in the current directory.

mkdir projekte

Mehrere Verzeichnisse Multiple Directories

Erstellt alle angegebenen Ordner auf einmal (auf gleicher Ebene). Creates all specified folders at once (on the same level).

mkdir docs bilder scripts

2. Wichtige Optionen (Flags) 2. Essential Options (Flags)

Flag ErklärungExplanation
-p Parents: Dies ist die wichtigste Option. Sie erlaubt das Erstellen von verschachtelten Verzeichnisstrukturen (Unterordner in Unterordnern), ohne dass die übergeordneten Ordner bereits existieren müssen. Außerdem unterdrückt sie Fehlermeldungen, falls ein Ordner bereits existiert. Parents: This is the most important option. It allows the creation of nested directory trees (subfolders within subfolders) without requiring the parent folders to already exist. It also suppresses error messages if a folder already exists.
-v Verbose (Ausführlich): Gibt für jedes erfolgreich erstellte Verzeichnis eine Bestätigungsmeldung auf dem Bildschirm aus. Sehr nützlich in Skripten oder in Kombination mit -p. Verbose: Prints a confirmation message to the screen for each successfully created directory. Very useful in scripts or in combination with -p.
-m Mode (Berechtigungen): Erlaubt es, die Dateiberechtigungen (im Oktal-Format wie bei chmod) direkt beim Erstellen des Ordners festzulegen, anstatt die Standard-Umask zu verwenden. Mode (Permissions): Allows you to set the file permissions (in octal format like chmod) directly when creating the folder, bypassing the default umask.

Beispiele:Examples:

Verschachtelte Struktur erstellen (Erstellt src, darin js, darin components):Create nested structure (Creates src, then js inside it, then components inside that):

mkdir -p src/js/components

Ordner direkt mit Lese-/Schreibrechten für alle (777) erstellen:Create folder directly with read/write permissions for everyone (777):

mkdir -m 777 public_share

3. Brace Expansion (Profi-Tipp) 3. Brace Expansion (Pro Tip)

In der Bash und Zsh können Sie geschweifte Klammern {} verwenden (Brace Expansion), um komplexe Verzeichnisstrukturen mit einem einzigen Befehl zu erstellen. Dies ist extrem effizient für das Scaffolding von Projekten. In Bash and Zsh, you can use curly braces {} (Brace Expansion) to create complex directory structures with a single command. This is extremely efficient for scaffolding projects.

Mehrere Unterordner in einem ZielordnerMultiple subfolders in one target folder

Erstellt den Ordner project und darin gleichzeitig src, bin und doc. Vergessen Sie nicht das -p Flag! Creates the project folder and simultaneously src, bin, and doc inside it. Don't forget the -p flag!

mkdir -p project/{src,bin,doc}

Jahres- und Monatsordner generierenGenerate year and month folders

Nutzt Zahlenbereiche (..), um Ordner für die Jahre 2024 bis 2026 zu erstellen, und darin jeweils Ordner für die Monate 01 bis 12. Dies generiert auf einen Schlag 36 Ordner! Uses number ranges (..) to create folders for the years 2024 to 2026, and inside each, folders for months 01 to 12. This generates 36 folders instantly!

mkdir -p archive/{2024..2026}/{01..12}

4. Häufige Fehler 4. Common Errors

File exists

mkdir: cannot create directory 'backup': File exists

Ursache: Es gibt bereits eine Datei oder einen Ordner mit exakt diesem Namen.
Lösung: Nutzen Sie mkdir -p backup, um den Fehler zu ignorieren, falls es ein Ordner ist, oder wählen Sie einen anderen Namen. Cause: A file or folder with exactly this name already exists.
Solution: Use mkdir -p backup to silently ignore the error if it's a directory, or choose a different name.

No such file or directory

mkdir: cannot create directory 'a/b/c': No such file or directory

Ursache: Sie versuchen, einen verschachtelten Ordner (c) zu erstellen, aber die übergeordneten Ordner (a oder b) existieren noch nicht.
Lösung: Hängen Sie das Flag -p an: mkdir -p a/b/c. Cause: You are trying to create a nested folder (c), but the parent folders (a or b) do not exist yet.
Solution: Append the -p flag: mkdir -p a/b/c.

Permission denied

mkdir: cannot create directory '/etc/myconfig': Permission denied

Ursache: Sie haben keine Schreibrechte in dem Verzeichnis, in dem Sie den neuen Ordner anlegen wollen (hier z.B. /etc).
Lösung: Stellen Sie sudo voran: sudo mkdir /etc/myconfig. Cause: You do not have write permissions in the directory where you are trying to create the new folder (e.g., /etc).
Solution: Prefix with sudo: sudo mkdir /etc/myconfig.

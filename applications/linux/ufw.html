UFW Setup & Referenz UFW Setup & Reference

UFW (Uncomplicated Firewall) ist ein benutzerfreundliches Frontend für die Verwaltung von iptables oder nftables Firewall-Regeln unter Linux. Es wurde entwickelt, um die Konfiguration einer Firewall zu vereinfachen, ohne auf mächtige Funktionen verzichten zu müssen. Dieser Guide behandelt die Installation, grundlegende Sicherheitspraktiken und fortgeschrittenes Regel-Management. UFW (Uncomplicated Firewall) is a user-friendly frontend for managing iptables or nftables firewall rules on Linux. It is designed to make configuring a firewall easier without sacrificing powerful features. This guide covers installation, basic security practices, and advanced rule management.

1. Einführung & Installation 1. Intro & Installation

Auf Debian/Ubuntu-Systemen ist UFW oft bereits vorinstalliert. Für andere Distributionen (wie Arch Linux) steht es in den offiziellen Repositories zur Verfügung. Offizielles Ubuntu Wiki (UFW). On Debian/Ubuntu systems, UFW is often pre-installed. For other distributions (like Arch Linux), it is available in the official repositories. Official Ubuntu Wiki (UFW).

Installation (Debian/Ubuntu) Installation (Debian/Ubuntu)

sudo apt update sudo apt install ufw

Installation (Arch Linux) Installation (Arch Linux)

sudo pacman -S ufw sudo systemctl enable --now ufw.service

Status prüfen Checking Status

Prüfen Sie, ob die Firewall aktiv ist und welche Regeln derzeit gelten: Check if the firewall is active and which rules currently apply:

sudo ufw status sudo ufw status verbose sudo ufw status numbered

Der Zusatz numbered ist extrem nützlich, um später spezifische Regeln zu löschen. The numbered flag is extremely useful for deleting specific rules later.

2. Grundlagen & Aktivierung 2. Basics & Enabling

Standardrichtlinien (Defaults)Default Policies

Policy

Die Standardeinstellung für Firewalls ist in der Regel das Blockieren aller eingehenden Verbindungen und das Zulassen aller ausgehenden Verbindungen. The standard configuration for firewalls is generally to block all incoming connections and allow all outgoing connections.

sudo ufw default deny incoming sudo ufw default allow outgoing

SSH erlauben & AktivierenAllow SSH & Enable

ACHTUNG: Wenn Sie sich über SSH auf einem Remote-Server befinden, MÜSSEN Sie SSH erlauben, bevor Sie UFW aktivieren. Andernfalls sperren Sie sich selbst aus! WARNING: If you are connected to a remote server via SSH, you MUST allow SSH before enabling UFW. Otherwise, you will lock yourself out!

1. SSH Erlauben:1. Allow SSH:

sudo ufw allow ssh

Alternativ: sudo ufw allow 22/tcp (oder Ihr spezifischer SSH-Port, falls geändert). Alternatively: sudo ufw allow 22/tcp (or your specific SSH port if changed).

2. UFW Aktivieren / Deaktivieren:2. Enable / Disable UFW:

sudo ufw enable sudo ufw disable

3. Verbindungen steuern 3. Controlling Traffic

Nach Ports & ProtokollenBy Ports & Protocols

Spezifische Ports erlauben:Allowing specific ports:

sudo ufw allow 80/tcp # HTTP sudo ufw allow 443/tcp # HTTPS sudo ufw allow 53/udp # DNS

Port-Bereiche (Ranges) erlauben:Allowing port ranges:

Bei Port-Bereichen MÜSSEN Sie das Protokoll (tcp oder udp) angeben. When specifying port ranges, you MUST include the protocol (tcp or udp).

sudo ufw allow 6000:6007/tcp sudo ufw allow 6000:6007/udp

Spezifische IPs / SubnetzeSpecific IPs / Subnets

Verbindung von einer IP erlauben (Alle Ports):Allow connection from an IP (All ports):

sudo ufw allow from 192.168.1.50

IP für spezifischen Port erlauben:Allow IP for a specific port:

sudo ufw allow from 192.168.1.50 to any port 22

Ganzes Subnetz erlauben:Allow entire Subnet:

sudo ufw allow from 10.0.0.0/24 to any port 3306

Verbindungen blockieren (Deny):Block connections (Deny):

sudo ufw deny from 203.0.113.4

4. Erweitert & Löschen 4. Advanced & Deleting

Regeln löschenDeleting Rules

Es gibt zwei Möglichkeiten, Regeln zu löschen: Nach ihrer Nummer (einfacher) oder nach der exakten Regel. There are two ways to delete rules: By their number (easier) or by the exact rule definition.

Methode 1: Nach Nummer (Empfohlen)Method 1: By Number (Recommended)

sudo ufw status numbered sudo ufw delete 2

Methode 2: Nach exakter RegelMethod 2: By exact rule

sudo ufw delete allow 80/tcp

Rate Limiting, Apps & LoggingRate Limiting, Apps & Logging

Rate Limiting (Schutz vor Brute-Force):Rate Limiting (Brute-Force protection):

Blockiert eine IP, wenn sie innerhalb von 30 Sekunden 6 oder mehr Verbindungen versucht (Ideal für SSH). Blocks an IP if it attempts 6 or more connections within 30 seconds (Ideal for SSH).

sudo ufw limit ssh

Application Profiles (App-Profile):Application Profiles:

Software wie Apache oder Nginx hinterlegen eigene Profile für UFW. Software like Apache or Nginx register their own profiles with UFW.

sudo ufw app list sudo ufw allow 'Nginx Full'

Logging aktivieren:Enable Logging:

sudo ufw logging on

Logs werden in /var/log/ufw.log gespeichert. Logs are stored in /var/log/ufw.log.

Notfall: UFW ZurücksetzenEmergency: Reset UFW

Löscht alle aktiven Regeln und deaktiviert die Firewall (Vorsicht!). Deletes all active rules and disables the firewall (Use with caution!).

sudo ufw reset

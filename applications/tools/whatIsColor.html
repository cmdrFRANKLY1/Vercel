Farbcodes & Farbräume Color Codes & Spaces

Ein Farbcode ist eine maschinenlesbare Repräsentation einer Farbe innerhalb eines Farbmodells. Auf Computern begegnen uns dabei vor allem RGB (Bildschirm), HEX (Web) und CMYK (Druck). Für Design, Barrierefreiheit und Bildverarbeitung kommen zusätzlich HSL, HSV, Lab und OKLCH zum Einsatz.

A color code is a machine-readable representation of a color inside a color model. On computers, the most common are RGB (screens), HEX (web), and CMYK (print). For design, accessibility, and image processing, HSL, HSV, Lab, and OKLCH are added on top.

1. Grundlagen der Farbe 1. Color Basics

Farbe ist keine physikalische Eigenschaft von Objekten, sondern eine Wahrnehmung. Sie entsteht im Gehirn aus der Auswertung von Licht unterschiedlicher Wellenlänge, das auf die Zapfen der Netzhaut trifft.

Color is not a physical property of objects but a perception. It arises in the brain from evaluating light of different wavelengths hitting the cones of the retina.

Diese beiden Begriffe werden oft verwechselt, sind aber streng zu trennen:

These two terms are often confused but must be strictly separated:

2. RGB & additive Farbmischung 2. RGB & Additive Mixing

2.1 Additive Farbmischung 2.1 Additive Color Mixing

Bildschirme leuchten selbst. Sie mischen Licht in den drei Grundfarben Rot, Grün und Blau. Je mehr Licht addiert wird, desto heller wird das Ergebnis:

Screens emit light. They mix light in the three primaries red, green, and blue. The more light you add, the brighter the result:

2.2 RGB-Werte, Kanäle & Bittiefe 2.2 RGB Values, Channels & Bit Depth

Ein RGB-Wert besteht aus drei Zahlen, je eine pro Kanal. Die typische Kodierung nutzt 8 Bit pro Kanal, was Werte von 0 bis 255 ergibt:

An RGB value consists of three numbers, one per channel. The typical encoding uses 8 bits per channel, giving values from 0 to 255:

BittiefeBit Depth WertebereichValue Range Anzahl FarbenNumber of Colors EinsatzUse
8 Bit / Kanal 0 – 255 256³ = 16.777.216 Web, Standard-DisplaysWeb, standard displays
10 Bit / Kanal 0 – 1023 1024³ ≈ 1,07 Mrd. HDR, moderne DisplaysHDR, modern displays
16 Bit / Kanal 0 – 65535 65536³ ≈ 2,8 × 10¹⁴ Fotobearbeitung, FarbkorrekturPhoto editing, color grading
32 Bit Float 0.0 – 1.0+ quasi unbegrenzt VFX, CompositingVFX, compositing

Warum mehr Bits? Höhere Bittiefe bedeutet feinere Abstufungen und weniger Banding. Ein Verlauf von Schwarz zu Weiß zeigt bei 8 Bit rund 256 Stufen, bei 10 Bit bereits 1024.

Why more bits? Higher bit depth means finer gradations and less banding. A black-to-white gradient shows about 256 steps at 8-bit, but 1024 steps at 10-bit.

2.3 Hex-Codes verstehen 2.3 Understanding Hex Codes

Ein Hex-Code ist eine kompakte Schreibweise für RGB, bei der jeder Kanal als zweistellige Hexadezimalzahl (Basis 16) dargestellt wird:

A hex code is a compact notation for RGB, where each channel is written as a two-digit hexadecimal (base-16) number:

#RRGGBB

Conversion: #4C = 4×16 + 12 = 76 in decimal. So #4C91FF becomes rgb(76, 145, 255).

3. Weitere Farbmodelle 3. Other Color Models

3.1 HSL & HSV — menschenfreundliche Modelle 3.1 HSL & HSV — Human-Friendly Models

RGB ist für Menschen schwer zu lesen. HSL und HSV beschreiben Farben stattdessen mit anschaulichen Komponenten:

RGB is hard to read for humans. HSL and HSV instead describe colors with intuitive components:

KomponenteComponent BedeutungMeaning
Hue (H) Farbton als Winkel 0° – 360° auf dem Farbkreis (0 = Rot, 120 = Grün, 240 = Blau).Hue as an angle 0° – 360° on the color wheel (0 = red, 120 = green, 240 = blue).
Saturation (S) Sättigung 0 – 100 %. 0 % = Graustufe, 100 % = voll gesättigt.Saturation 0 – 100%. 0% = gray, 100% = fully saturated.
Lightness (L) Nur HSL: Helligkeit 0 – 100 %. 0 % = Schwarz, 100 % = Weiß, 50 % = reine Farbe.HSL only: lightness 0 – 100%. 0% = black, 100% = white, 50% = pure color.
Value (V) Nur HSV: Helligkeit 0 – 100 %. 0 % = Schwarz, 100 % = volle Helligkeit.HSV only: value 0 – 100%. 0% = black, 100% = full brightness.

HSL ist nicht Lab. Eine gleichmäßige Erhöhung der Lightness in HSL führt nicht zu einer wahrnehmungsmäßig gleichmäßigen Aufhellung — dafür braucht man OKLCH oder Lab.

HSL is not Lab. Increasing lightness linearly in HSL does not produce a perceptually uniform brightness change — that requires OKLCH or Lab.

3.2 CMYK — subtraktive Farbmischung für den Druck 3.2 CMYK — Subtractive Mixing for Print

Beim Druck wird kein Licht addiert, sondern es werden Pigmente auf Papier gemischt, die Licht schlucken. Die Grundfarben sind Cyan, Magenta, Yellow und Key (Schwarz).

In print, light is not added — pigments are mixed on paper that absorb light. The primaries are cyan, magenta, yellow, and key (black).

PunktPoint ErklärungExplanation
Warum K?Why K? Theoretisch ergibt C+M+Y = Schwarz, in der Praxis aber ein schmutziges Dunkelbraun. K liefert echtes Schwarz und spart Farbe.Theoretically C+M+Y = black, but in practice a dirty dark brown. K delivers true black and saves ink.
WertebereichValue Range Jede Komponente 0 – 100 %. cmyk(0%, 100%, 100%, 0%) ist Rot.Each component 0 – 100%. cmyk(0%, 100%, 100%, 0%) is red.
VerlustLossiness RGB → CMYK ist verlustbehaftet: leuchtende Bildschirmfarben lassen sich oft nicht drucken (Out-of-Gamut).RGB → CMYK is lossy: vivid screen colors often cannot be printed (out-of-gamut).

3.3 CIE Lab & XYZ — wahrnehmungsbasierte Modelle 3.3 CIE Lab & XYZ — Perceptual Models

CIE XYZ (1931) war das erste Modell, das alle für den Menschen sichtbaren Farben unabhängig von einem Gerät beschreibt. Auf ihm baut CIE Lab (1976) auf, das bewusst wahrnehmungsmäßig gleichmäßig konstruiert ist:

CIE XYZ (1931) was the first model to describe all human-visible colors independent of any device. CIE Lab (1976) builds on it and is intentionally perceptually uniform:

AchseAxis BedeutungMeaning
L*Helligkeit von 0 (Schwarz) bis 100 (Weiß).Lightness from 0 (black) to 100 (white).
a*Grün (negativ) ↔ Rot (positiv).Green (negative) ↔ red (positive).
b*Blau (negativ) ↔ Gelb (positiv).Blue (negative) ↔ yellow (positive).

Wozu? Lab wird verwendet, wenn Farbabstände (ΔE) berechnet werden sollen, etwa in der Druckvorstufe oder in Farbmanagementsystemen. Die moderne Web-Variante heißt OKLCH (CSS Color 4) und ist deutlich einfacher zu rechnen.

Why? Lab is used whenever color distances (ΔE) must be computed, e.g. in prepress or color management. The modern web variant is OKLCH (CSS Color 4), which is much easier to compute.

4.2 Gamut-Mapping & Out-of-Gamut 4.2 Gamut Mapping & Out-of-Gamut

Wenn eine Farbe in einem engeren Farbraum nicht dargestellt werden kann, spricht man von Out-of-Gamut. Es gibt drei Strategien:

When a color cannot be represented in a narrower space, it is out-of-gamut. There are three strategies:

  • Clipping: Werte werden auf das Maximum gekappt — führt zu harten Farbabrissen.Values are clamped to the maximum — results in harsh color breaks.
  • Kompressions-Mapping: Der gesamte Gamut wird weich gestaucht, um alle Farben zu erhalten.The entire gamut is softly compressed to preserve all colors.
  • Perceptual Rendering: Wahrnehmungsoptimiertes Mapping, Standard bei ICC-Profilen.Perception-optimized mapping, standard in ICC profiles.

5.1 WCAG-Kontrast & Barrierefreiheit 5.1 WCAG Contrast & Accessibility

Die Web Content Accessibility Guidelines definieren Mindestkontraste zwischen Text und Hintergrund. Der Kontrast wird als Verhältnis (1:1 bis 21:1) berechnet:

The Web Content Accessibility Guidelines define minimum contrast ratios between text and background, from 1:1 up to 21:1:

StufeLevel Normaler TextNormal Text Großer Text / UILarge Text / UI
AA 4,5 : 1 3,0 : 1
AAA 7,0 : 1 4,5 : 1

Faustregel: Bei Text, der kleiner als 18 pt (bzw. 14 pt fett) ist, gilt die strengere Grenze. Für Web-Interfaces ist WCAG AA das Mindestziel.

Rule of thumb: For text smaller than 18 pt (or 14 pt bold), the stricter limit applies. WCAG AA is the minimum target for web interfaces.

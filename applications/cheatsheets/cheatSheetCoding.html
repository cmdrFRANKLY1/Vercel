This reference combines a visual coding block builder with a cross-language reference. Assemble blocks into an algorithm — and instantly see how the same flow looks in pseudocode, Python, JavaScript, Java, C#, and C++. All examples are for educational purposes only.

1. Coding-Block Baukasten 1. Coding Block Builder

Klicke links auf einen Baustein, um ihn in das aktive Einfügeziel (gestrichelter Rahmen) einzufügen. Klicke auf einen anderen gestrichelten Rahmen, um das Ziel zu wechseln – so entstehen verschachtelte Bedingungen und Schleifen. Du kannst Blöcke auch per Drag & Drop verschieben: Zieh einen Block auf die obere Hälfte eines anderen Blocks, um ihn davor einzufügen – oder auf die untere Hälfte, um ihn danach einzufügen. So bekommst du einen Block auch ganz leicht wieder aus einer Bedingung heraus, indem du ihn auf einen Block außerhalb ziehst. Bausteine aus der Palette lassen sich ebenso direkt an eine solche Position ziehen.

Click a block on the left to insert it into the active insert target (dashed outline). Click another dashed outline to switch the target — this is how nested conditions and loops are created. You can also drag & drop blocks: drag a block onto the top half of another block to insert it before it — or onto the bottom half to insert it after it. This makes it easy to pull a block out of a condition by dragging it onto a block outside. Palette blocks can also be dragged straight into such a position.

2. Bedingungen & Operatoren 2. Conditions & Operators

Eine Bedingung ist ein Ausdruck, der zu einem Wahrheitswert (true / false) ausgewertet wird. Sie steuert, ob ein Block ausgeführt wird.

A condition is an expression that evaluates to a boolean value (true / false). It controls whether a block is executed.

Achtung: = ist keine Gleichheit! Caution: = is not equality! In fast allen Sprachen bedeutet = eine Zuweisung, == einen Vergleich. In Python ist = sogar ein Syntaxfehler innerhalb einer Bedingung, in JavaScript vergleicht == mit Typumwandlung – deshalb dort besser === verwenden. In almost all languages = means assignment while == means comparison. In Python, = inside a condition is a syntax error; in JavaScript, == coerces types — so prefer === there.

Kurzschlussauswertung (Short-Circuit): Bei A && B wird B nur ausgewertet, wenn A wahr ist. Bei A || B wird B nur ausgewertet, wenn A falsch ist. Das ist wichtig, um Fehler zu vermeiden, z. B. if (liste != null && liste.length > 0).

Short-circuit evaluation: With A && B, B is only evaluated if A is true. With A || B, B is only evaluated if A is false. This matters for avoiding errors, e.g. if (list != null && list.length > 0).

Off-by-One-FalleOff-by-one trap Pythons range(1, 11) erzeugt 1…10 – die obere Grenze ist exklusiv. In Java/C#/C++ schreibt man dagegen i <= 10 (inklusiv). Wer das verwechselt, erhält einen Durchlauf zu viel oder zu wenig. Python's range(1, 11) yields 1…10 — the upper bound is exclusive. In Java/C#/C++ you write i <= 10 (inclusive). Mixing these up gives one iteration too many or too few.

Statisch vs. dynamisch: Python und JavaScript sind dynamisch typisiert (der Typ hängt am Wert), Java, C# und C++ sind statisch typisiert (der Typ wird bei der Deklaration festgelegt).

Static vs. dynamic: Python and JavaScript are dynamically typed (the type belongs to the value), while Java, C# and C++ are statically typed (the type is fixed at declaration).

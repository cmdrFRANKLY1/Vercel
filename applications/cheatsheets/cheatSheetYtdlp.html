yt-dlp & ffmpeg Referenzyt-dlp & ffmpeg Reference

Umfassende Referenz für yt-dlp (Video-Downloader) und ffmpeg (Multimedia-Framework). Diese Werkzeuge sind unverzichtbar für die Automatisierung von Medien-Workflows, Konvertierung, Schneiden und Archivierung. ffmpeg ist zudem eine Voraussetzung für viele yt-dlp-Funktionen wie das Zusammenführen von Video und Audio.

Comprehensive reference for yt-dlp (video downloader) and ffmpeg (multimedia framework). These tools are essential for automating media workflows, conversion, trimming, and archiving. ffmpeg is also required for many yt-dlp features like merging video and audio.

1. Einführung & Installation 1. Introduction & Installation

Bevor Sie mit den Befehlen arbeiten, stellen Sie sicher, dass beide Tools installiert und im Systempfad (PATH) verfügbar sind. yt-dlp ist ein eigenständiges Python-Programm, während ffmpeg als statische Binärdatei oder über Paketmanager installiert werden kann.

Before working with the commands, ensure both tools are installed and available in your system PATH. yt-dlp is a standalone Python program, while ffmpeg can be installed as a static binary or via package managers.

EmpfehlungRecommendation
ffmpegVor der Nutzung von yt-dlp installieren. Wird für das Merging von Video- und Audiospuren benötigt.Install before using yt-dlp. Required for merging video and audio streams.
PATHStellen Sie sicher, dass der Installationsordner in der Umgebungsvariable PATH eingetragen ist.Ensure the installation folder is added to the PATH environment variable.

3. ffmpeg Befehle 3. ffmpeg Commands

ffmpeg ist das Schweizer Taschenmesser der Medienverarbeitung. Die folgenden Befehle decken die häufigsten Aufgaben ab. Beachten Sie, dass ffmpeg für viele Operationen eine Kombination aus Eingabeoptionen (vor -i) und Ausgabeoptionen (nach -i) erfordert.

ffmpeg is the Swiss Army knife of media processing. The following commands cover the most common tasks. Note that many operations require a combination of input options (before -i) and output options (after -i).

3.1 Grundlegende Konvertierung 3.1 Basic Conversion

AktionActionBefehlCommand
Einfache Konvertierung (Codec-Kopie)Simple Conversion (Stream Copy) ffmpeg -i input.mp4 -c copy output.mkv
MP4 zu H.264/AAC (Web-freundlich)MP4 to H.264/AAC (Web-friendly) ffmpeg -i input.avi -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 128k output.mp4
Auflösung ändernChange Resolution ffmpeg -i input.mp4 -vf "scale=1280:720" output.mp4
Seitenverhältnis beibehaltenMaintain Aspect Ratio ffmpeg -i input.mp4 -vf "scale=1280:-1" output.mp4
Bildrate ändernChange Frame Rate ffmpeg -i input.mp4 -r 30 output.mp4
Video-Codec ändernChange Video Codec ffmpeg -i input.mp4 -c:v libx265 output.mp4

3.2 Audio extrahieren 3.2 Extract Audio

AktionActionBefehlCommand
Audio extrahieren (MP3)Extract Audio (MP3) ffmpeg -i input.mp4 -vn -c:a libmp3lame -q:a 2 output.mp3
Audio extrahieren (AAC, ohne Re-Encode)Extract Audio (AAC, No Re-encode) ffmpeg -i input.mp4 -vn -c:a copy output.aac
Audio für Spracherkennung (16kHz, Mono)Audio for Speech Recognition (16kHz, Mono) ffmpeg -i input.mp4 -ar 16000 -ac 1 audio.wav
Audio-Bitrate ändernChange Audio Bitrate ffmpeg -i input.mp4 -vn -b:a 192k output.mp3
Lautstärke anpassenAdjust Volume ffmpeg -i input.mp4 -af "volume=1.5" output.mp4

3.3 Schneiden & Trimmen 3.3 Trim & Cut

4. Workflow-Tipps 4. Workflow Tips

yt-dlp + ffmpegyt-dlp + ffmpeg

Stellen Sie sicher, dass ffmpeg im PATH ist, damit yt-dlp Video- und Audiospuren automatisch zusammenführen kann. Dies ist der wichtigste Schritt für hochwertige Downloads.

Ensure ffmpeg is in PATH so yt-dlp can automatically merge video and audio streams. This is the most important step for high-quality downloads.

Batch-VerarbeitungBatch Processing

Nutzen Sie eine Textdatei mit URLs und den Befehl yt-dlp -a urls.txt, um mehrere Videos in einem Durchgang herunterzuladen. Ideal für Playlists oder Serien.

Use a text file with URLs and the command yt-dlp -a urls.txt to download multiple videos in one go. Ideal for playlists or series.

Formate prüfenCheck Formats

Verwenden Sie immer yt-dlp -F "URL", um die verfügbaren Formate zu sehen. So wählen Sie gezielt die gewünschte Qualität und den Codec aus.

Always use yt-dlp -F "URL" to see available formats. This lets you specifically choose the desired quality and codec.

ArchivierungArchiving

Verwenden Sie --download-archive archive.txt, um zu verhindern, dass bereits heruntergeladene Videos erneut geladen werden. Besonders bei wiederkehrenden Playlist-Downloads nützlich.

Use --download-archive archive.txt to prevent already downloaded videos from being downloaded again. Especially useful for recurring playlist downloads.

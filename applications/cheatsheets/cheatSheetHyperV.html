Microsoft Hyper-V Microsoft Hyper-V

Hyper-V ist Microsofts hardwarebasierte Virtualisierungslösung. Als Typ-1-Hypervisor greift es direkt auf die physische Hardware zu, um virtuelle Maschinen (VMs) zu erstellen und zu verwalten, was eine hohe Leistung und Isolation für Enterprise-Umgebungen gewährleistet. Hyper-V is Microsoft's hardware-based virtualization solution. As a Type-1 hypervisor, it interacts directly with physical hardware to create and manage virtual machines (VMs), ensuring high performance and isolation for enterprise environments.

1. Grundkonzepte 1. Core Concepts

1.1 Typ-1 Hypervisor (Bare-Metal) 1.1 Type-1 Hypervisor (Bare-Metal)

Im Gegensatz zu Programmen wie VirtualBox (Typ-2), läuft Hyper-V direkt auf der physischen Hardware (Bare-Metal). Das "Host-Betriebssystem" (die Parent Partition) läuft eigentlich neben den VMs, verwaltet sie aber durch direkte Hypercalls an den Hypervisor. Unlike programs like VirtualBox (Type-2), Hyper-V runs directly on physical hardware (Bare-Metal). The "Host OS" (Parent Partition) actually runs alongside the VMs, but manages them via direct hypercalls to the hypervisor.

3.2 Checkpoints (Snapshots) 3.2 Checkpoints (Snapshots)

Ein Checkpoint friert den Zustand (und optional den RAM) einer VM zu einem bestimmten Zeitpunkt ein. Nützlich vor Updates. A checkpoint freezes the state (and optionally memory) of a VM at a specific point in time. Useful before updates. 

# Standard Checkpoint erstellen / Create
Checkpoint-VM -Name "Web-01" -SnapshotName "Pre-Patch"

# Zu Checkpoint zurückkehren / Revert
Restore-VMCheckpoint -Name "Web-01" -SnapshotName "Pre-Patch"

Comprehensive compendium of essential terminal commands for IT System Integration training. Includes key Linux commands (Bash) and Windows commands (CMD and PowerShell) for administration, troubleshooting, and system configuration.

3. Rechte & Benutzer 3. Permissions & Users

In Linux-Systemen werden Dateirechte strikt nach dem Owner-Group-Others (UGO) Modell geregelt. Die Benutzerverwaltung erfolgt über zentrale Systemdateien und Befehle.

In Linux systems, file permissions are strictly governed by the Owner-Group-Others (UGO) model. User management is handled through central system files and CLI utilities.

3.1 Linux Chmod Oktal-Tabelle 3.1 Linux Chmod Octal Table

4 = Read (r)

Berechtigung zum Lesen des Inhalts.

Permission to read file contents.

2 = Write (w)

Berechtigung zum Schreiben / Ändern.

Permission to write / modify.

1 = Execute (x)

Berechtigung zum Ausführen als Programm.

Permission to execute as a program.

0 = None (-)

Keinerlei Berechtigungen.

No permissions granted.

Kommando / BeispielCommand / ExampleBeschreibungDescription
chmod 755 script.sh Owner hat rwx (7), Gruppe und andere haben r-x (5). Standard für ausführbare Skripte.Owner gets rwx (7), group and others get r-x (5). Standard for executable scripts.
chmod 600 id_rsa Nur der Besitzer darf lesen und schreiben (z.B. essenziell für SSH Private Keys).Only owner can read/write (essential security for SSH private keys).
chmod -R 750 /var/www Rekursive Rechtevergabe für Verzeichnisse und Dateien.Recursive permission assignment across directories and files.
chown -R user:group /dir Ändert den Besitzer (User) und die Gruppe einer Datei oder eines Ordners rekursiv.Recursively changes the user owner and group of a file or folder.

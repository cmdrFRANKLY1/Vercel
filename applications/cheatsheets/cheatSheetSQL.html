SQL (Structured Query Language) ist die Standard-Sprache zur Kommunikation mit relationalen Datenbanken. Sie ermöglicht es uns, Datenstrukturen zu definieren (DDL), Daten zu manipulieren (DML) und komplexe Abfragen zu stellen (DQL). 16.1 DDL – Data Definition LanguageData Definition Language

Definiert und ändert die Struktur der Datenbank (Tabellen, Indexe, Views, Schemas). Defines and modifies the structure of the database (tables, indexes, views, schemas).

CREATE DATABASE DDL

Erstellt eine neue Datenbank.Creates a new database.

CREATE DATABASE shop_db;
CREATE DATABASE IF NOT EXISTS shop_db
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;
CREATE TABLE DDL

Erstellt eine neue Tabelle mit Spalten, Datentypen und Constraints.Creates a new table with columns, data types, and constraints.

CREATE TABLE kunden (
    id        INT PRIMARY KEY AUTO_INCREMENT,
    name      VARCHAR(100) NOT NULL,
    email     VARCHAR(150) UNIQUE,
    ort       VARCHAR(50),
    angelegt  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX DDL

Erstellt einen Index zur Beschleunigung von Abfragen. UNIQUE erzwingt Eindeutigkeit.Creates an index to speed up queries. UNIQUE enforces uniqueness.

CREATE INDEX idx_ort ON kunden(ort);
CREATE UNIQUE INDEX idx_email ON kunden(email);
CREATE VIEW DDL

Erstellt eine virtuelle Tabelle aus einer gespeicherten Abfrage.Creates a virtual table from a stored query.

CREATE VIEW v_berliner AS
SELECT id, name, email FROM kunden
WHERE ort = 'Berlin';
ALTER TABLE DDL

Ändert eine bestehende Tabelle: Spalte hinzufügen, ändern, löschen oder Constraint ergänzen.Modifies an existing table: add, modify, drop column or add constraint.

ALTER TABLE kunden ADD COLUMN telefon VARCHAR(20);
ALTER TABLE kunden ALTER COLUMN name VARCHAR(150);
ALTER TABLE kunden DROP COLUMN telefon;
ALTER TABLE kunden ADD CONSTRAINT chk_ort CHECK (ort <> '');
DROP / TRUNCATE / RENAME DDL

DROP löscht Struktur + Daten. TRUNCATE leert die Tabelle, behält Struktur. RENAME benennt um.DROP deletes structure + data. TRUNCATE empties the table, keeps structure. RENAME renames.

DROP TABLE kunden;
DROP TABLE IF EXISTS kunden;
DROP INDEX idx_ort;
DROP VIEW v_berliner;
TRUNCATE TABLE kunden;
RENAME TABLE kunden TO customer;

16.2 DML – Data Manipulation LanguageData Manipulation Language

Verändert die Daten in bestehenden Tabellen. Modifies the data inside existing tables.

INSERT DML

Fügt neue Zeilen ein. Mehrere Werte-Paare oder INSERT aus SELECT möglich.Inserts new rows. Multiple value pairs or INSERT from SELECT possible.

INSERT INTO kunden (name, email, ort)
VALUES ('Alice', 'alice@mail.com', 'Berlin');

INSERT INTO kunden (name, email, ort) VALUES
    ('Bob',   'bob@mail.com',   'Hamburg'),
    ('Carol', 'carol@mail.com', 'München');

INSERT INTO kunden_archiv (name, email)
SELECT name, email FROM kunden WHERE angelegt < '2020-01-01';
UPDATE DML

Ändert bestehende Zeilen. Ohne WHERE werden alle Zeilen geändert!Modifies existing rows. Without WHERE, all rows are changed!

UPDATE kunden
SET email = 'neu@mail.com', ort = 'Köln'
WHERE id = 1;
DELETE DML

Löscht Zeilen. Ohne WHERE wird die gesamte Tabelle geleert!Deletes rows. Without WHERE, the entire table is emptied!

DELETE FROM kunden WHERE id = 1;
DELETE FROM kunden WHERE angelegt < '2020-01-01';
MERGE / UPSERT DML

Fügt ein oder aktualisiert, falls bereits vorhanden. Syntax DBMS-abhängig (Oracle: MERGE, MySQL: INSERT … ON DUPLICATE KEY UPDATE, PostgreSQL: INSERT … ON CONFLICT).Inserts or updates if already exists. Syntax DBMS-dependent (Oracle: MERGE, MySQL: INSERT … ON DUPLICATE KEY UPDATE, PostgreSQL: INSERT … ON CONFLICT).

-- PostgreSQL
INSERT INTO kunden (id, name)
VALUES (1, 'Alice')
ON CONFLICT (id) DO UPDATE
    SET name = EXCLUDED.name;

16.3 DQL – Data Query LanguageData Query Language

Liest Daten aus der Datenbank. Im Kern: SELECT mit seinen Klauseln. Reads data from the database. Core: SELECT with its clauses.

SELECT (vollständige Syntax) DQL

Die zentrale Abfrageklausel. Reihenfolge und Ausführungsreihenfolge beachten!The central query clause. Note the order and execution order!

SELECT DISTINCT spalte1 AS alias1, COUNT(*)
FROM tabelle AS t
WHERE bedingung
GROUP BY spalte1
HAVING COUNT(*) > 5
ORDER BY spalte1 DESC
LIMIT 10 OFFSET 20;

Ausführungsreihenfolge: FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT Execution order: FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT

WHERE – Operatoren DQL

Filter für einzelne Zeilen vor der Gruppierung.Filter for individual rows before grouping.

WHERE preis BETWEEN 10 AND 100
  AND kategorie IN ('A', 'B', 'C')
  AND name LIKE 'A%'          -- % = beliebig viele, _ = genau ein Zeichen
  AND rabatt IS NOT NULL
  AND NOT (ort = 'Berlin' OR ort = 'Hamburg');
JOIN-Typen DQL

Verknüpft Zeilen aus zwei oder mehr Tabellen über gemeinsame Spalten.Combines rows from two or more tables via shared columns.

-- INNER JOIN: nur Treffer in beiden Tabellen
SELECT * FROM a INNER JOIN b ON a.id = b.a_id;

-- LEFT JOIN: alles aus a + Treffer aus b
SELECT * FROM a LEFT JOIN b ON a.id = b.a_id;

-- RIGHT JOIN: alles aus b + Treffer aus a
SELECT * FROM a RIGHT JOIN b ON a.id = b.a_id;

-- FULL OUTER JOIN: alles aus beiden
SELECT * FROM a FULL OUTER JOIN b ON a.id = b.a_id;

-- CROSS JOIN: kartesisches Produkt
SELECT * FROM a CROSS JOIN b;

-- SELF JOIN: Tabelle mit sich selbst verknüpfen
SELECT e.name AS mitarbeiter, m.name AS chef
FROM employees e
LEFT JOIN employees m ON e.chef_id = m.id;
Aggregatfunktionen DQL

Fassen Werte mehrerer Zeilen zu einem Ergebnis zusammen. Oft mit GROUP BY kombiniert.Aggregate values of multiple rows into one result. Often combined with GROUP BY.

SELECT
    COUNT(*) AS anzahl,
    COUNT(DISTINCT ort) AS anzahl_orte,
    SUM(preis) AS summe,
    AVG(preis) AS durchschnitt,
    MIN(preis) AS min_preis,
    MAX(preis) AS max_preis
FROM produkte
GROUP BY kategorie
HAVING COUNT(*) > 5;
Mengenoperatoren DQL

Kombinieren zwei Ergebnismengen. Beide SELECTs müssen dieselbe Spaltenzahl und kompatible Typen haben.Combine two result sets. Both SELECTs must have the same number of columns and compatible types.

SELECT name FROM kunden
UNION              -- Vereinigung, Duplikate entfernt
SELECT name FROM lieferanten;

SELECT name FROM kunden
UNION ALL          -- Vereinigung, Duplikate bleiben
SELECT name FROM lieferanten;

SELECT name FROM kunden
INTERSECT          -- Schnittmenge
SELECT name FROM lieferanten;

SELECT name FROM kunden
EXCEPT             -- Differenz (in kunden, nicht in lieferanten)
SELECT name FROM lieferanten;
Subqueries & EXISTS DQL

Verschachtelte Abfrage in SELECT, FROM, WHERE oder HAVING.Nested query in SELECT, FROM, WHERE, or HAVING.

-- Skalar-Subquery im WHERE
SELECT name FROM kunden
WHERE umsatz > (SELECT AVG(umsatz) FROM kunden);

-- IN-Subquery
SELECT name FROM kunden
WHERE id IN (SELECT kunden_id FROM bestellungen);

-- EXISTS
SELECT name FROM kunden k
WHERE EXISTS (
    SELECT 1 FROM bestellungen b WHERE b.kunden_id = k.id
);

-- ANY / ALL
WHERE preis > ALL (SELECT preis FROM produkte WHERE kat = 'X');
CASE WHEN DQL

If-then-else-Logik direkt in SQL.If-then-else logic directly in SQL.

SELECT name, preis,
    CASE
        WHEN preis < 10  THEN 'günstig'
        WHEN preis < 100 THEN 'mittel'
        ELSE 'teuer'
    END AS preisklasse
FROM produkte;

16.4 DCL – Data Control LanguageData Control Language

Steuert Berechtigungen und Zugriffsrechte. Controls permissions and access rights.

GRANT / REVOKE / DENY DCL

GRANT erteilt Rechte, REVOKE entzieht sie, DENY verweigert explizit (überschreibt GRANT).GRANT grants rights, REVOKE removes them, DENY explicitly denies (overrides GRANT).

GRANT SELECT, INSERT ON kunden TO alice;
GRANT ALL PRIVILEGES ON kunden TO admin WITH GRANT OPTION;
REVOKE INSERT ON kunden FROM alice;
DENY DELETE ON kunden TO alice;

-- Rolle erstellen und zuweisen
CREATE ROLE reporting;
GRANT SELECT ON kunden TO reporting;
GRANT reporting TO alice;

16.5 TCL – Transaction Control LanguageTransaction Control Language

Steuert Transaktionen (Alles-oder-Nichts-Prinzip). Controls transactions (all-or-nothing principle).

BEGIN / COMMIT / ROLLBACK TCL

Startet, bestätigt oder verwirft eine Transaktion.Starts, commits, or rolls back a transaction.

BEGIN TRANSACTION;   -- oder: START TRANSACTION
UPDATE konto SET saldo = saldo - 100 WHERE id = 1;
UPDATE konto SET saldo = saldo + 100 WHERE id = 2;
COMMIT;                -- bestätigen
-- oder bei Fehler:
ROLLBACK;              -- verwerfen
SAVEPOINT TCL

Setzt einen Speicherpunkt innerhalb einer Transaktion, zu dem partiell zurückgerollt werden kann.Sets a savepoint within a transaction to which a partial rollback is possible.

BEGIN;
INSERT INTO kunden (name) VALUES ('Alice');
SAVEPOINT sp1;
INSERT INTO kunden (name) VALUES ('Bob');
ROLLBACK TO sp1;   -- nur Bob wird verworfen
COMMIT;

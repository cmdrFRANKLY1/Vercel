SQL (Structured Query Language) ist die Standard-Sprache zur Kommunikation mit relationalen Datenbanken. Sie ermöglicht es uns, Datenstrukturen zu definieren (DDL), Daten zu manipulieren (DML) und komplexe Abfragen zu stellen (DQL), um Erkenntnisse aus Rohdaten zu gewinnen. SQL (Structured Query Language) is the standard language for communicating with relational databases. It allows us to define data structures (DDL), manipulate data (DML), and perform complex queries (DQL) to extract insights from raw data.

1. Grundkonzepte 1. Core Concepts

1.1 Relationale Datenbanken (RDBMS) 1.1 Relational Databases (RDBMS)

Ein Relationales Datenbankmanagementsystem speichert Daten in Form von Tabellen (Relationen). Jede Tabelle besteht aus Spalten (Attribute) und Zeilen (Datensätze). Tabellen können über gemeinsame Felder miteinander verknüpft (relatiert) werden. A Relational Database Management System stores data in the form of tables (relations). Each table consists of columns (attributes) and rows (records). Tables can be linked (related) to each other using shared fields.

1.2 Primär- & Fremdschlüssel 1.2 Primary & Foreign Keys

Primärschlüssel (Primary Key)Primary Key (PK)

Ein eindeutiger Identifikator für jeden Datensatz in einer Tabelle. Darf niemals `NULL` sein und muss einzigartig (UNIQUE) sein. (z.B. `user_id`). A unique identifier for each record in a table. It must never be `NULL` and must be completely unique. (e.g., `user_id`).

Fremdschlüssel (Foreign Key)Foreign Key (FK)

Ein Feld in einer Tabelle, das auf den Primärschlüssel einer anderen Tabelle verweist, um eine Beziehung herzustellen (Referentielle Integrität). A field in a table that references the Primary Key of another table to establish a relationship (Referential Integrity).

2. DDL (Data Definition Language) 2. DDL (Data Definition Language)

DDL-Befehle werden verwendet, um die Struktur der Datenbank zu definieren, zu ändern oder zu löschen. DDL commands are used to define, alter, or drop the structure of the database.

CREATE TABLE

Erstellt eine neue Tabelle mit definierten Spalten und Datentypen. Creates a new table with defined columns and data types. 

CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

3. DML (Data Manipulation Language) 3. DML (Data Manipulation Language)

DML-Befehle verwalten die eigentlichen Daten innerhalb der Tabellen (CRUD-Operationen außer Read). DML commands manage the actual data within the tables (CRUD operations excluding Read).

INSERT

INSERT INTO users (username, email)
VALUES ('Alice', 'alice@mail.com');

UPDATE

UPDATE users 
SET email = 'new@mail.com' 
WHERE id = 1;

DELETE

Vergiss niemals die WHERE-Klausel, sonst löschst du die gesamte Tabelle! Never forget the WHERE clause, or you will delete the entire table! 

DELETE FROM users WHERE id = 1;

4. DQL (Data Query Language) 4. DQL (Data Query Language)

DQL besteht hauptsächlich aus dem SELECT-Befehl. Er wird verwendet, um Daten abzufragen und zu filtern. DQL primarily consists of the SELECT command. It is used to query and filter data.

4.1 Anatomie einer Abfrage 4.1 Anatomy of a Query 

SELECT column1, COUNT(column2)  -- 1. Was wollen wir sehen? (Projektion)
FROM table_name               -- 2. Woher kommen die Daten? (Relation)
WHERE condition               -- 3. Filter für Zeilen
GROUP BY column1              -- 4. Gruppierung für Aggregationen
HAVING COUNT(column2) > 5     -- 5. Filter für gruppierte Daten
ORDER BY column1 DESC         -- 6. Sortierung (ASC/DESC)
LIMIT 10;                     -- 7. Begrenzung der Ausgabe

MPV Setup & Referenz MPV Setup & Reference

MPV ist ein freier, quelloffener Mediaplayer, der auf MPlayer und mplayer2 basiert. Er zeichnet sich durch hohe Wiedergabequalität, umfangreiche Hardware-Beschleunigung, Skriptfähigkeit und eine nahezu vollständig über Konfigurationsdateien steuerbare Oberfläche aus. Dieser Guide behandelt Installation, Konfiguration, Keybindings, Shader, Skripte und Frontends. MPV is a free, open-source media player based on MPlayer and mplayer2. It stands out for its high playback quality, extensive hardware acceleration, scriptability, and an interface that is almost entirely controllable through configuration files. This guide covers installation, configuration, keybindings, shaders, scripts, and frontends.

1. Einführung & Installation 1. Intro & Installation

MPV ist in den offiziellen Repositories nahezu aller Distributionen verfügbar. Für die aktuellste Version empfiehlt sich zusätzlich das offizielle mpv-build-Repository oder ein Flatpak. MPV is available in the official repositories of almost all distributions. For the latest version, the official mpv-build repository or a Flatpak is recommended.

Installation (Debian/Ubuntu) Installation (Debian/Ubuntu)

sudo apt update sudo apt install mpv yt-dlp

yt-dlp ist optional und ermöglicht das direkte Abspielen von Streaming-URLs. yt-dlp is optional and enables direct playback of streaming URLs.

Installation (Arch Linux) Installation (Arch Linux)

sudo pacman -S mpv yt-dlp # Alternative aus dem AUR (aktueller): paru -S mpv-git

Das mpv-git-Paket enthält die neuesten Entwickler-Features, kann aber instabiler sein. The mpv-git package contains the latest developer features but may be less stable.

Version prüfen & unterstützte Features Check version & supported features

Mit --version sehen Sie die einkompilierten Features (Hardware-Decoder, Ausgabe-Backends). Achten Sie auf VAAPI, VDPAU bzw. cuda, je nach GPU. With --version you can see the compiled-in features (hardware decoders, output backends). Look for VAAPI, VDPAU, or cuda, depending on your GPU.

mpv --version mpv --list-options | grep hwdec

2. Grundlagen & Konfiguration 2. Basics & Configuration

MPV liest seine Konfiguration aus ~/.config/mpv/ (Linux/macOS) bzw. %APPDATA%\mpv\ (Windows). Die wichtigsten Dateien sind mpv.conf (Optionen), input.conf (Tastenkürzel) und der scripts/-Ordner. MPV reads its configuration from ~/.config/mpv/ (Linux/macOS) or %APPDATA%\mpv\ (Windows). The most important files are mpv.conf (options), input.conf (keybindings), and the scripts/ folder.

Konfigurationsverzeichnis anlegen:Create configuration directory:

mkdir -p ~/.config/mpv/scripts mkdir -p ~/.config/mpv/shaders touch ~/.config/mpv/mpv.conf touch ~/.config/mpv/input.conf

Grundlegende Wiedergabe:Basic playback:

mpv video.mkv mpv --fullscreen film.mp4 mpv --sub-file=subs.srt video.mkv mpv https://example.com/stream.m3u8

mpv.conf & Profilempv.conf & Profiles

Empfohlene Grundeinstellungen:Recommended base settings:

# ~/.config/mpv/mpv.conf # Ausgabe-Backend (modern, beste Qualität) vo=gpu-next gpu-api=vulkan # Hardware-Dekodierung hwdec=auto-safe # Untertitel sub-auto=fuzzy sub-file-paths=subs:sub:subtitles slang=de,en # Audio audio-file-auto=fuzzy alang=de,en # Zwischenspeicher für Netzwerkstreams (in MiB) cache=yes demuxer-max-bytes=500M demuxer-readahead-secs=20 # Wiedergabe-Verhalten keep-open=yes save-position-on-quit=yes watch-later-options=start,volume,mute # Oberfläche osd-bar=yes osd-duration=2000 volume-max=150

Profile definieren:Define profiles:

# Profil für Anime mit Untertiteln [anime] profile-desc="Anime" sub-ass-override=force sub-font="Noto Sans" sub-font-size=42 sub-border-size=2.5 sub-shadow-offset=1 # Profil für hochwertige Wiedergabe [high-quality] profile-desc="Hohe Qualität" scale=ewa_lanczossharp cscale=ewa_lanczossharp dscale=mitchell video-sync=display-resample interpolation=yes tscale=oversample # Profil automatisch laden, wenn Dateiname "anime" enthält [anime-auto] profile-desc="Auto Anime" profile=anime profile-cond=filename:find("anime") ~= nil

Profile lassen sich manuell mit --profile=anime aufrufen oder per profile-cond automatisch aktivieren. Profiles can be invoked manually with --profile=anime or activated automatically via profile-cond.

3. Hardware-Beschleunigung 3. Hardware Acceleration

MPV unterstützt eine Vielzahl von Hardware-Decodern. Die richtige Wahl hängt von Ihrer GPU ab. Prüfen Sie zuerst mit vainfo (Intel/AMD) bzw. nvidia-smi, welche Codecs unterstützt werden. MPV supports a wide range of hardware decoders. The right choice depends on your GPU. First check with vainfo (Intel/AMD) or nvidia-smi which codecs are supported.

GPU-HerstellerGPU Vendor hwdec-Werthwdec value BemerkungNote
Intel (iGPU) vaapi Zuverlässig, breite Codec-UnterstützungReliable, broad codec support
AMD (Mesa) vaapi Sehr gute Unterstützung ab GCN 1.2Very good support from GCN 1.2 onwards
NVIDIA nvdec Benötigt proprietären TreiberRequires proprietary driver
AutomatischAutomatic auto-safe Empfohlen für EinsteigerRecommended for beginners

Beispielkonfiguration Intel / AMD:Example config Intel / AMD:

# ~/.config/mpv/mpv.conf vo=gpu-next gpu-api=vulkan hwdec=vaapi hwdec-extra-frames=16 # Für ältere GPUs oder X11 ohne Vulkan: # vo=gpu # gpu-api=opengl # gpu-context=x11egl

Beispielkonfiguration NVIDIA:Example config NVIDIA:

# ~/.config/mpv/mpv.conf vo=gpu-next gpu-api=vulkan hwdec=nvdec hwdec-extra-frames=8 # Für CUDA-basierte Dekodierung: # hwdec=cuda

Bei Problemen (Bildfehler, grüne Streifen) hilft oft --hwdec=no zur Diagnose. Alternativ --vo=null zum reinen Benchmark. If issues occur (artifacts, green stripes), --hwdec=no often helps for diagnosis. Alternatively --vo=null for pure benchmarking.

4. Skripte & Erweiterungen 4. Scripts & Extensions

MPV kann über Lua- und JavaScript-Skripte erweitert werden. Skripte werden einfach in ~/.config/mpv/scripts/ abgelegt und beim nächsten Start automatisch geladen. MPV can be extended via Lua and JavaScript scripts. Scripts are simply placed in ~/.config/mpv/scripts/ and loaded automatically on next start.

Beliebte Skripte installieren:Install popular scripts:

cd ~/.config/mpv/scripts # Autoload: lädt nächste Datei im Ordner automatisch curl -LO https://raw.githubusercontent.com/mpv-player/mpv/master/TOOLS/lua/autoload.lua # Thumbnail-Suche (Vorschau beim Spulen) curl -LO https://raw.githubusercontent.com/thec0d3r/mpv-thumbnail-script/master/thumbnails.lua # ModernX: moderne OSD-Oberfläche git clone https://github.com/cyl0/ModernX.git cp ModernX/modernx.lua . # mpvacious: Anki-Karten aus Untertiteln erstellen git clone https://github.com/Ajatt-Tools/mpvacious.git cp -r mpvacious ~/.config/mpv/scripts/

yt-dlp-Integration aktivieren:Enable yt-dlp integration:

# ~/.config/mpv/mpv.conf ytdl=yes ytdl-format=bestvideo+bestaudio/best script-opts=ytdl_hook-ytdl_path=yt-dlp # Beispiel: YouTube-Video direkt abspielen # mpv https://www.youtube.com/watch?v=XXXXXXXXXXX

Für den besten Effekt sollte yt-dlp regelmäßig aktualisiert werden (yt-dlp -U), da sich Streaming-Dienste ständig ändern. For best results, yt-dlp should be updated regularly (yt-dlp -U), since streaming services change constantly.

5. Frontends & IPC 5. Frontends & IPC

Grafische FrontendsGraphical Frontends

MPV ist primär ein CLI-Player. Wer eine Maus-Oberfläche bevorzugt, kann auf eines dieser Frontends zurückgreifen — sie nutzen MPV im Hintergrund als Wiedergabe-Engine. MPV is primarily a CLI player. Those who prefer a mouse-driven interface can use one of these frontends — they use MPV as the underlying playback engine.

  • Celluloid — GTK-Frontend, Standard bei vielen Distros default on many distros
  • SMPlayer — Qt-basiert, sehr funktionsreich very feature-rich
  • mpv.net — Windows-FrontendWindows frontend
  • IINA — macOS, native OptikmacOS, native look

IPC-Socket & AutomatisierungIPC Socket & Automation

Über einen Unix-Socket kann MPV von externen Programmen (Skripte, Steuerungs-Apps) ferngesteuert werden — nützlich für Home-Theater-Setups oder automatisches Streaming. Via a Unix socket, MPV can be controlled remotely by external programs (scripts, control apps) — useful for home theater setups or automated streaming.

mpv --input-ipc-server=/tmp/mpvsocket video.mkv # Befehl an MPV senden echo '{ "command": ["toggle", "pause"] }' | \ socat - /tmp/mpvsocket

MPV als Standard-Player setzen Set MPV as default player

Unter Linux lässt sich MPV als Standard für die gängigen Video- und Audio-MIME-Typen registrieren. Bei Desktop-Umgebungen kann auch einfach das Standardprogramm in den Systemeinstellungen geändert werden. On Linux, MPV can be registered as the default for common video and audio MIME types. In desktop environments, the default program can also simply be changed in system settings.

# Standard-MIME-Typen auf mpv.desktop setzen xdg-mime default mpv.desktop video/mp4 xdg-mime default mpv.desktop video/x-matroska xdg-mime default mpv.desktop video/webm xdg-mime default mpv.desktop audio/mpeg xdg-mime default mpv.desktop audio/flac

6. Wartung & Fehlersuche 6. Maintenance & Troubleshooting

Updates einspielenApplying updates

MPV wird über die Paketverwaltung aktualisiert. Bei yt-dlp empfiehlt sich das eingebaute Update, um Streaming-Probleme zu vermeiden. MPV is updated via the package manager. For yt-dlp, the built-in update is recommended to avoid streaming issues.

sudo apt update && sudo apt upgrade mpv # yt-dlp aktualisieren sudo yt-dlp -U # oder (empfohlen): pipx upgrade yt-dlp

Logs & DiagnoseLogs & Diagnostics

Bei Wiedergabeproblemen zeigt -v detaillierte Logs. Für tiefgehende Fehlersuche kann das Log-Level schrittweise bis -v -v -v erhöht werden. For playback issues, -v shows detailed logs. For deeper debugging, the log level can be increased up to -v -v -v.

mpv -v video.mkv 2>&1 | tee mpv.log mpv --msg-level=all=v video.mkv # Nur Codec-Informationen anzeigen mpv --no-video --vo=null --frames=1 video.mkv

Konfiguration sichern Backup configuration

Die gesamte MPV-Konfiguration inklusive Skripten und Shadern passt in ein kleines Archiv. So lässt sie sich einfach auf einen neuen Rechner übertragen. The entire MPV configuration, including scripts and shaders, fits in a small archive. This makes it easy to transfer to a new machine.

# Backup erstellen tar -czf mpv-config-$(date +%F).tar.gz -C ~/.config mpv # Wiederherstellen tar -xzf mpv-config-2024-01-01.tar.gz -C ~/.config

Konfiguration automatisch synchronisieren (Git):Synchronize configuration automatically (Git):

cd ~/.config/mpv git init git add . git commit -m "Initial MPV config" git remote add origin git@github.com:user/mpv-config.git git push -u origin main

Mit .gitignore können Sie Caches, Watch-Later-Dateien und Logs ausschließen: watch_later/, *.log. With .gitignore you can exclude caches, watch-later files, and logs: watch_later/, *.log.

Samba Setup & Referenz Samba Setup & Reference

Samba ist eine freie Software-Suite, die das Server Message Block (SMB) bzw. Common Internet File System (CIFS) Protokoll implementiert. Es ermöglicht die nahtlose Datei- und Druckerfreigabe zwischen Linux/Unix-Servern und Windows-, macOS- oder anderen Linux-Clients. Dieser Guide behandelt Installation, Konfiguration von öffentlichen/privaten Shares und die Benutzerverwaltung. Samba is a free software suite that implements the Server Message Block (SMB) or Common Internet File System (CIFS) protocol. It enables seamless file and print sharing between Linux/Unix servers and Windows, macOS, or other Linux clients. This guide covers installation, configuring public/private shares, and user management.

1. Einführung & Installation 1. Intro & Installation

Samba ist in den Standard-Repositories fast aller Linux-Distributionen verfügbar. Samba is available in the standard repositories of almost all Linux distributions.

Installation (Debian/Ubuntu) Installation (Debian/Ubuntu)

sudo apt update sudo apt install samba smbclient

Installation (Arch Linux) Installation (Arch Linux)

sudo pacman -S samba sudo systemctl enable --now smb nmb

Dienste überprüfen Checking Services

Samba besteht hauptsächlich aus zwei Daemons: smbd (für Datei-/Druckdienste und Authentifizierung) und nmbd (für NetBIOS-Namensauflösung). Samba mainly consists of two daemons: smbd (for file/print services and authentication) and nmbd (for NetBIOS name resolution).

sudo systemctl status smbd sudo systemctl status nmbd

2. Globale Konfiguration 2. Global Configuration

Die Hauptkonfigurationsdatei von Samba ist /etc/samba/smb.conf. Bevor Sie Änderungen vornehmen, ist es ratsam, ein Backup der Originaldatei zu erstellen. The main configuration file for Samba is /etc/samba/smb.conf. Before making changes, it is advisable to back up the original file.

Backup erstellen:Create a backup:

sudo cp /etc/samba/smb.conf /etc/samba/smb.conf.backup

Globale Einstellungen bearbeiten:Edit global settings:

Suchen Sie nach dem Block [global]. Hier definieren Sie grundlegende Parameter wie die Arbeitsgruppe (Workgroup). Look for the [global] block. Here you define basic parameters such as the Workgroup.

[global] workgroup = WORKGROUP server string = Samba Server %v netbios name = debian-server security = user map to guest = bad user dns proxy = no

map to guest = bad user ist wichtig, um anonymen Zugriff (Gast-Zugriff) für Freigaben ohne Passwortabfrage zu erlauben. map to guest = bad user is important to allow anonymous (guest) access for shares without password prompts.

3. Freigaben einrichten 3. Setting up Shares

Öffentliche Freigabe (Ohne Passwort)Public Share (No Password)

1. Verzeichnis erstellen & Rechte setzen:1. Create directory & set permissions:

sudo mkdir -p /srv/samba/public sudo chmod -R 0775 /srv/samba/public sudo chown -R nobody:nogroup /srv/samba/public

2. In smb.conf eintragen:2. Add to smb.conf:

[Public] path = /srv/samba/public browsable = yes writable = yes guest ok = yes read only = no create mask = 0664 directory mask = 0775

Authentifizierte Freigabe (Privat)Authenticated Share (Private)

1. Verzeichnis erstellen & Rechte setzen:1. Create directory & set permissions:

sudo mkdir -p /srv/samba/private sudo chown -R root:sambashare /srv/samba/private sudo chmod -R 0770 /srv/samba/private

2. In smb.conf eintragen:2. Add to smb.conf:

[Private] path = /srv/samba/private valid users = @sambashare browsable = yes writable = yes guest ok = no read only = no

Das @ vor sambashare bedeutet, dass der Zugriff für alle Mitglieder dieser Linux-Gruppe erlaubt ist. Alternativ können Sie auch spezifische Nutzernamen (z.B. valid users = john, jane) verwenden. The @ before sambashare means access is allowed for all members of this Linux group. Alternatively, you can specify individual usernames (e.g., valid users = john, jane).

4. Samba-Benutzerverwaltung 4. Samba User Management

Samba verwaltet seine Passwörter unabhängig vom Linux-System. Ein Benutzer muss zwingend als Linux-Benutzer existieren, bevor er als Samba-Benutzer hinzugefügt werden kann. Samba manages its passwords independently from the Linux system. A user must exist as a Linux user before they can be added as a Samba user.

Benutzer erstellen und Passwort setzen:Create user and set password:

# 1. Linux-Benutzer erstellen (falls nicht vorhanden) sudo adduser username # 2. Zur Gruppe 'sambashare' hinzufügen (für Private Share) sudo usermod -aG sambashare username # 3. Samba-Passwort setzen sudo smbpasswd -a username

Samba aktivieren & Benutzer aktivieren:Enable Samba & activate user:

sudo smbpasswd -e username

Dienste neu startenRestart Services

Nach jeder Änderung an der smb.conf oder nach dem Hinzufügen von Benutzern sollten die Samba-Dienste neu gestartet werden. After making changes to smb.conf or adding users, the Samba services should be restarted.

sudo systemctl restart smbd nmbd

Dauerhaft Mounten (Linux fstab) Permanent Mount (Linux fstab)

Um eine Samba-Freigabe dauerhaft in Linux einzubinden, installieren Sie cifs-utils und fügen Sie einen Eintrag in die /etc/fstab ein: To permanently mount a Samba share in Linux, install cifs-utils and add an entry to /etc/fstab:

//192.168.1.100/Private /mnt/samba cifs username=username,password=secret,uid=1000,gid=1000 0 0

Sicherer ist die Verwendung einer credentials-Datei anstelle des Passworts im Klartext! It is safer to use a credentials file instead of putting the password in plain text!

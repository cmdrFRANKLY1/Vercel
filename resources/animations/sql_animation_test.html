2 Die drei Schlüsselarten

Datenbanken lösen das Duplikat-Problem mit Schlüsseln. Jeder hat eine eigene Farbe.

K

Kandidatenschlüssel

Jede Spalte, die einen eindeutigen Wert pro Zeile hätte. Zwei Kandidaten konkurrieren – hier ID und E-Mail.

PK

Primärschlüssel

Der gewählte, offizielle Ausweis einer Zeile. Er darf nie NULL und nie doppelt sein.

FK

Fremdschlüssel

Ein Verweis in einer anderen Tabelle. Er zeigt auf den Primärschlüssel und stellt die Verbindung her.

Aufgabe: IPv6 Subnetze bilden Task: Build IPv6 subnets
Wir erhalten ein /48 Präfix vom Provider. We receive a /48 prefix from the provider.
Ziel: Wir brauchen /64 Netzwerke für unsere Standorte! 👉 Goal: We need /64 networks for our locations! 👉
Schritt 1: Subnetz-Bits berechnen Step 1: Calculate subnet bits
Wir berechnen die Differenz zwischen Ziel (/64) und Basis (/48). We calculate the difference between target (/64) and base (/48).
Das ergibt die Bits für unsere Subnetz-ID. This gives us the bits for our subnet ID.
Schritt 2: Den 4. Block lokalisieren Step 2: Locate the 4th block
Ein IPv6 Block (Hextett) ist exakt 16 Bit lang. An IPv6 block (hextet) is exactly 16 bits long.
Das bedeutet, unser 4. Block ist komplett für Subnetze reserviert! This means our 4th block is completely reserved for subnets!
Schritt 3: Hexadezimal hochzählen Step 3: Count up in hexadecimal
Nun zählen wir den 4. Block einfach hoch. Now we simply count up the 4th block.
Achtung: Wir zählen Hexadezimal (0-9, dann a, b, c, d, e, f). Note: We count in hexadecimal (0-9, then a, b, c, d, e, f).
Schritt 4: IPs im Subnetz Step 4: IPs in the subnet
Bei IPv6 gibt es keinen Broadcast mehr. In IPv6 there is no broadcast anymore.
Die restlichen 64 Bit sind für die Hosts (Geräte) verfügbar. The remaining 64 bits are available for hosts (devices).
